# 首航探测器搭建指南

这是一台使用 Aeronautics 便携式发动机与 Create 传动件的紧凑型探测器，适合近程采样和熟悉损管。它具有两个独立推进通道、两个配平舱、密闭乘员舱、回声探测仪与采样货舱。

## 船坞与材料

先在地幔顶部岩体中开挖干燥船坞，并建立接驳站补给。准备约一百个耐火舱壳、两个观察窗、四个耐压舱门、两个熔岩推进器、两个配平舱，以及各一个舱室调节器、回声探测仪和地幔采样器。另备七台便携式发动机、两个齿轮箱、两个离合器、两个换向齿轮箱、四个拉杆、一个完整照明方块、物理装配器、强力胶和燃煤。

携带冷却芯、维修包与应急封堵板，预留背包和货舱空间。取得安山机壳后，可通过原版配方书查找设备配方。

## 舱壳与坐标

以船体西北下角为 `(0,0,0)`，X 向东、Y 向上、Z 向南。先搭建宽 5、高 4、长 7 的封闭外壳，即 X=0–4、Y=0–3、Z=0–6；内部 X=1–3、Y=1–2、Z=1–5 保持干燥。

下面的设备替换相应位置的外壳。设备朝向表示其面板或工作面朝向，旋转动力从背面接入。

| 位置 | 放置内容 | 朝向或用途 |
| --- | --- | --- |
| `(1,1,0)`、`(1,2,0)` | 地幔观察窗 | 船首观察 |
| `(2,1,0)` | 舱室调节器 | 面板朝南，通风口朝舱内 |
| `(2,2,0)` | 耐压舱门 | 单格检修口，航行时关闭 |
| `(3,1,0)` | 地幔采样器 | 朝北，船首采样 |
| `(1,0,2)`、`(3,0,2)` | 地幔配平舱 | 朝上，背部轴朝下 |
| `(1,1,6)`、`(3,1,6)` | 熔岩推进器 | 朝南，背部轴朝舱内 |
| `(0,1,2)`、`(0,2,2)` | 耐压舱门 | 同朝向朝西，构成两格高登船口 |
| `(2,3,3)` | 海晶灯或萤石 | 使用完整照明方块，保持舱顶围护 |

在舱内 `(2,1,3)` 放置朝北的回声探测仪。保留登船口到前部乘员位置的通路，查看控制台时站在 `(2,1,2)` 附近。需要更宽敞的维修通道时，可以扩大船体并相应增加配平能力。

## 发动机与操控

给七台发动机分别加入煤炭。普通燃煤提供 32 RPM，首次检查不需要增速。

| 发动机位置 | 输出朝向 | 连接设备 |
| --- | --- | --- |
| `(2,1,-1)` | 朝南 | 舱室调节器 |
| `(3,1,1)` | 朝北 | 地幔采样器 |
| `(2,1,4)` | 朝北 | 回声探测仪 |
| `(1,-1,3)`、`(3,-1,3)` | 朝北 | 经齿轮箱向上连接配平舱 |
| `(1,1,3)`、`(3,1,3)` | 朝南 | 左右推进传动通道 |

在 `(1,-1,2)` 与 `(3,-1,2)` 放置齿轮箱，调整到南北与上下均有轴孔，使下方发动机能驱动上面的配平舱。两台配平舱在 32 RPM 时保持深度；总主动配平容量为 256 质量单位。改装和增载后检查是否需要增加配平舱。

左右推进通道沿 Z 轴依次连接：

**发动机 Z=3 → 离合器 Z=4 → 换向齿轮箱 Z=5 → 推进器 Z=6。**

在每个离合器与换向齿轮箱上方放置拉杆。离合器拉杆打开时断开推进，关闭时接通推进；出航前先将两个离合器拉杆打开。左右换向杆统一切换可改变行进方向，单独停止一侧推进器可转弯。

本布局的推进器正转推动船体向南，反转向北；两侧换向杆均打开时朝北部采样口行进。熟悉后可用红石链路将控制移到更方便的位置，或改用无线控制器。增速与升降传动可在后续改装时加入。

## 装配与首航

1. 在干燥环境中完成围护与传动，关闭全部舱门。调节器与探测仪应已获得动力；用空手查看设备状态，并向调节器补充冷却。
2. 用强力胶连接船体、舱内设备、外置发动机和下方齿轮箱。检查胶合范围，避免连接船坞地面或支架。
3. 在舱顶放置物理装配器，连接到船体并按 Aeronautics 的装配操作组装。打开侧面登船口，进入舱内并关闭。两块登船舱门会联动开关。
4. 完整装配体包括舱顶装配器、下方发动机和船首发动机。为全部轮廓预留空间；本例船坞通道建议至少宽 7、高 8 格，船坞内还需保留改装和装卸空间。
5. 打开船坞与熔岩海之间的机械开口，确认推进器和配平舱浸入熔岩，舱室保持密封。接通两侧推进，低速离坞，尝试停机、转向和倒车。
6. 用探测仪寻找附近矿体，靠近至采样器前方 4 格内。保持船位，采集后空手右键采样器卸货。参照基地距离与方位返航，在干燥船坞开舱并加工矿物、补充燃料和冷却。

配平只能在熔岩中工作，干燥船坞应有平整承托面。以船体全部方块都能进入的净空规划船坞门和航路。出航后先完成近程操控检查，再携带更多货物扩大航程。
