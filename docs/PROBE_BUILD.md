# 首航探测器搭建指南

这是一台使用熔岩换热发动机与 Create 传动件的紧凑型探测器，适合近程采样和熟悉损管。它具有两个独立推进通道、两个配平舱、密闭乘员舱、回声探测仪与采样货舱。

## 船坞与材料

先在地幔顶部岩体中开挖干燥船坞，并建立接驳站补给；钻头与岩体开挖布局见 [地幔整备基地开挖指南](DRILL_BUILD.md)。准备一百一十二个耐火舱壳、两个观察窗、三个耐压舱门、两个熔岩推进器、两个配平舱，以及各一个舱室调节器、回声探测仪和地幔采样器。另备七台熔岩换热发动机、两个齿轮箱、两个离合器、两个换向齿轮箱、四个拉杆、一个完整照明方块、物理装配器、强力胶和冷却芯。

携带冷却芯、维修包与应急封堵板，预留背包和货舱空间。取得安山机壳后，可通过原版配方书查找设备配方。

首航前备好原版下界砖和石英，用于耐火舱壳、电子管与回声探测仪。基础船体、采样、推进和损管设备不需要遗迹合金或谐振晶体；先具备近程作业能力，再用远征所得材料升级补给与个人装备。

标准艇实际安装 112 个耐火舱壳，制造舱门、观察窗和设备另消耗 27 个；按配方取整需先制成 144 个。完整成品清单、合成原料与基地加工顺序见[远征材料与基地加工](EXPEDITION_SUPPLIES.md)。

先用铁板进行 Create 序列装配，交替切割与压制八轮，取得发动机总成，再与高炉和铁板合成便携式发动机。每台便携式发动机再加三张铜板和一个 Create 储液罐，改造为熔岩换热发动机；七台共需额外二十一张铜板和七个储液罐。原机颜色不限，总成装配的失败产物另行回收。

先在干燥基地内放置并充能重生锚，确认重生点后再出航；预留萤石和备用补给。地幔中使用床会爆炸，床留作主世界或地核营地的重生设施。

## 舱壳与坐标

以船体西北下角为 `(0,0,0)`，X 向东、Y 向上、Z 向南。先搭建宽 5、高 4、长 7 的封闭外壳，即 X=0–4、Y=0–3、Z=0–6；内部 X=1–3、Y=1–2、Z=1–5 保持干燥。

下面的设备替换相应位置的外壳。设备朝向表示其面板或工作面朝向，旋转动力从背面接入。

| 位置 | 放置内容 | 朝向或用途 |
| --- | --- | --- |
| `(1,1,0)`、`(1,2,0)` | 地幔观察窗 | 船首观察 |
| `(2,1,0)` | 舱室调节器 | 面板朝南，通风口朝舱内 |
| `(2,2,0)` | 耐压舱门 | 单格检修口，航行时关闭 |
| `(3,1,0)` | 地幔采样器 | 朝北，船首采样 |
| `(1,0,2)`、`(3,0,2)` | 地幔配平舱 | 朝上，背部轴朝下 |
| `(1,1,6)`、`(3,1,6)` | 熔岩推进器 | 朝南，背部轴朝舱内 |
| `(0,1,2)`、`(0,2,2)` | 耐压舱门 | 同朝向朝西，构成两格高登船口 |
| `(2,3,3)` | 海晶灯或萤石 | 使用完整照明方块，保持舱顶围护 |
| `(0,-1,0)` 至 `(0,-1,6)`、`(4,-1,0)` 至 `(4,-1,6)` | 共十四个耐火舱壳 | 两条同高落地滑橇，与船底胶合 |

在舱内 `(2,1,3)` 放置朝北的回声探测仪。保留登船口到前部乘员位置的通路，查看控制台时站在 `(2,1,2)` 附近。需要更宽敞的维修通道时，可以扩大船体并相应增加配平能力。

两条滑橇与下方传动件的底面齐平，让船体落地时保持水平。改装后继续保持前后均有支撑，并为全部低位部件预留净空。

为安装和检修船底设备，在两条滑橇之间开一条检修沟：挖空 X=1–3、Y=-2、Z=-1–7，沟底保留在 Y=-3，两端连接地面。滑橇下方 X=0、4 的 Y=-2 承托面保持完整；检修沟两端的入口与头顶留足净空。干坞排干、船体落稳后，从沟内接近下方发动机与齿轮箱。

先铺滑橇并完成船底齿轮箱、发动机和配平舱，再封闭地板、侧壁与舱顶。冷却统一从舱内调节器补充。船体两侧可搭临时施工台，用台阶连接地面与舱顶；登船口外留出两格高通道，施工台下的低矮空间不要作为通路。封顶前确认舱内设备都能触及。

## 发动机与操控

换热发动机在已装配的探测器上工作，机组所在高度浸入地幔熔岩后输出 32 RPM，每台提供 1024 SU。发动机与舱室共用同艇调节器的冷却储备；冷却不足时停止输出，向调节器补入冷却芯后恢复。停机时也能补充冷却。

普通冷却芯提供 120 单位，稳定芯提供 240 单位，调节器容量为 600 单位。舱室散热每秒消耗 1 单位，每台运行的发动机另耗 0.1 单位；七台机组加一间舱室时，一枚普通芯约维持 70 秒。首航先装满储备并随身携带备用芯，低冷却时提前补充；停机会同时影响舱室供能。

长时间停泊或离艇探索前，可用 Create 机械手自动补给冷却：让工作面正对调节器，中间留一格空位，从侧轴接入旋转动力，并在上方连接朝下的漏斗。机械手保持右键使用模式，将普通冷却芯存入漏斗。储备能够容纳一枚完整冷却芯时才会消耗该芯；出航前检查机械手已有冷却芯、漏斗未被红石锁住，并保留手动补给的操作位置。

发动机正面的蓝绿色观察窗在换热运行时变亮。佩戴 Create 工程师护目镜，对准发动机查看工况与停机原因，对准舱室调节器查看密封、热负荷和冷却储备。补入冷却芯后会显示当前储备与容量；空间不足时保留冷却芯，并提示需要的空间。

用扳手调整设备、舱门和发动机朝向，让发动机输出轴朝向下表所列设备。干坞调试可临时接入手摇或燃煤动力，完成后拆除临时连接，再胶合装配。

| 发动机位置 | 输出朝向 | 连接设备 |
| --- | --- | --- |
| `(2,1,-1)` | 朝南 | 舱室调节器 |
| `(3,1,1)` | 朝北 | 地幔采样器 |
| `(2,1,4)` | 朝北 | 回声探测仪 |
| `(1,-1,3)`、`(3,-1,3)` | 朝北 | 经齿轮箱向上连接配平舱 |
| `(1,1,3)`、`(3,1,3)` | 朝南 | 左右推进传动通道 |

在 `(1,-1,2)` 与 `(3,-1,2)` 放置齿轮箱，调整到南北与上下均有轴孔，使下方发动机能驱动上面的配平舱。两台配平舱在 32 RPM 时保持深度；总主动配平容量为 256 质量单位。清空主手和副手后，潜行右键舱内可触及的配平舱顶面，依次切换转速控制、上浮、下潜，两台应选择相同模式。上浮或下潜模式在基础转速下即可升降；再次切回转速控制恢复定深。改装和增载后检查是否需要增加配平舱。

左右推进通道沿 Z 轴依次连接：

**发动机 Z=3 → 离合器 Z=4 → 换向齿轮箱 Z=5 → 推进器 Z=6。**

在每个离合器与换向齿轮箱上方放置拉杆。离合器拉杆打开时断开推进，关闭时接通推进；出航前先将两个离合器拉杆打开。左右换向杆统一切换可改变行进方向，单独停止一侧推进器可转弯。

需要小范围调整航向时，接通两侧推进并让两侧换向状态相反，可近似原地转向。接近所需方向时，短暂互换两侧换向状态以减小转速，随后断开两侧推进；停稳后再统一换向状态并恢复前进。

本布局中，两侧换向杆均关闭时朝北部采样口行进，均打开时倒车向南。熟悉后可用红石链路将控制移到更方便的位置，或改用无线控制器。需要更快升降时，可在转速控制模式下改装增速与换向传动。

## 装配与首航

1. 在干燥环境中完成围护与传动，向调节器装满冷却储备，携带备用芯，关闭全部舱门。干坞内换热发动机保持停机。
2. 用强力胶连接船体、舱内设备、外置发动机和下方齿轮箱。检查胶合范围，避免连接船坞地面或支架。
3. 在舱顶放置物理装配器，或将它安装到舱内 `(2,1,1)` 的地板上，并与船体连接。空手对准装配器，按住右键，向上拖动手柄到底，再松开右键完成装配。使用舱内装配器时，可先登船并关闭舱门再操作；两块登船舱门会联动开关。
4. 完整装配体包括物理装配器、下方发动机和船首发动机。为全部轮廓预留空间；本例船坞通道建议至少宽 7、高 8 格，船坞内还需保留改装和装卸空间。
5. 打开船坞机械开口和顶部灌流口，保持艇门关闭。船体与全部机组所在高度浸入熔岩后，确认发动机、调节器和探测仪启动，舱室完成密封，再接通两侧推进低速离坞，尝试停机、转向和倒车。
6. 用探测仪寻找附近矿体，靠近至采样器前方 6 格内。保持船位，采集后空手右键采样器卸货。参照基地距离与方位返航，在干燥船坞开舱并加工矿物、补充冷却和备件。

采样口需要与矿块处于同一高度。先断开两路推进，用配平舱短时上浮或下潜对齐，再切回转速控制稳定高度；确认采样器开始工作后保持船位。装配后检查实际采样口高度，再接近矿面。

接近矿脉时同时观察整艘艇的净空，特别是船首发动机和下方传动。矿面前方空间不足时，可先从矿脉下方绕到外侧，停机后再上浮对齐采样口。完成采集后先退回通畅航路，再朝基地行驶。

配平只能在熔岩中工作，干燥船坞应有平整承托面。以船体全部方块都能进入的净空规划船坞门和航路。出航后先完成近程操控检查，再携带更多货物扩大航程。

固定泊位的出口应尽量与艇门同高，并缩短熔岩中的转移距离。邻近设施旁先直行移出回转范围，再转向；返航时在宽敞水域调整姿态，随后可用倒车低速进泊。调查低位遗迹前，先准备不需要遗迹合金的隔热面罩，并留足返程的抗火药水和冷却补给。

## 灌流船坞

侧面开闸后，熔岩会沿坞底流动。为离坞准备单独的顶部灌流口，让落下的熔岩覆盖推进器；灌流与航行空间通过机械闸板控制，生活区和接驳出口保持隔离。

使用黏性机械活塞、离合器与换向器的具体布局见[机械灌流船坞搭建](DOCK_BUILD.md)。为顶部滑槽、升降闸槽和固定动力间扩建空间；高于熔岩海的基地需先向顶部储液槽供给熔岩。

上面的样艇可使用内部 X=-2–6、Y=-1–7、Z=-1–7 的独立坞室，底板位于 Y=-2，顶板位于 Y=8。南侧 Z=8 作为航行闸口；顶板 X=0–4、Z=-1–7 作为灌流口，其上方接熔岩源。灌流覆盖配平舱与推进器，使船体充分浸入熔岩后起浮。为闸板及其运动机构另留空间，用 Create 机械结构控制开合。

1. 关闭航行闸和灌流口，在干坞内完成装配、登船、关舱和冷却补给。
2. 打开航行闸与顶部灌流口，保持舱门关闭。确认船体、配平舱和推进器充分浸入熔岩，用上浮模式使滑橇离开承托面，再恢复定深并接通两侧推进，驶离坞室。
3. 返航时保持灌流和航行闸开启。使用两台配平舱的上浮模式，将滑橇升至坞底上方；切回转速控制稳定高度，再低速驶入。确认全部低位设备、船首发动机与尾部都已越过闸板后停机。
4. 关闭航行闸和顶部灌流口，等待流动熔岩消退，确认艇外通道干燥、船体落稳，再开舱。

将熔岩源留在可关闭的灌流口外，坞内采用流动熔岩。两条滑橇承担排干后的落地支撑；整备期间关闭灌流，补充冷却、备件和货舱物资。

## 护目镜与驾驶舱仪表

佩戴 Create 工程师护目镜，对准设备读取工况：调节器显示密封、热负荷和冷却；推进器、配平舱显示浸入状态、故障与配平；采样器显示进度和货舱；弩炮显示弹药与射击条件。

回声探测仪提供全艇读数，默认显示航行与舱务；按住 Shift 查看矿物、遗迹、生物及待维修部位的世界坐标。常态信息不会自动占用屏幕底部。罗盘操作、冷却补给与紧急情况仍会即时提示。

需要持续查看时，可在驾驶舱安装 Create 显示屏。**先装配船体，再用显示链接器选择显示屏并将链接器装在回声探测仪上**，在链接器界面选择一组数据：

| 数据源 | 内容 | 建议预留行数 |
| --- | --- | --- |
| 探测器：航行读数 | 世界位置、前方净空、航速、目的地方位和坐标 | 5 |
| 探测器：舱务读数 | 密封舱室、最高热负荷、共享冷却、换热机组与待维修数 | 5 |
| 探测器：勘探回波 | 矿物、遗迹、生物的位置和方位 | 7 |
| 探测器：损管清单 | 最多四处待维修部位的位置及剩余数量 | 9 |

显示屏需要从侧边齿轮接入旋转动力。精简航行面板可从三格宽开始；舱务、勘探和损管建议七格宽，坐标或名称较长时继续扩展。按数据组预留高度，或分设多块显示屏。链接器和显示屏与船体一同胶合。航行及存档重载后会继续更新；拆卸再装配后重新绑定显示屏。

## 干坞装卸与补给

采样货舱可使用普通漏斗接入 Aeronautics 对接连接器，同时将基地补给送入船载箱子。准备两个对接连接器、六个漏斗、三个箱子、一个拉杆和岸侧红石电源。向东扩建干坞装卸区，保证岸侧设备、传输通道和操作空间都处于干燥区域。

| 位置 | 装卸设备 | 朝向或用途 |
| --- | --- | --- |
| `(3,0,0)` | 船载漏斗 | 从上方采样器取货，朝东输出 |
| `(4,0,0)`、`(4,0,1)` | 船载漏斗 | 均朝南，将货物送向连接器 |
| `(4,0,2)` | 船侧对接连接器 | 朝东 |
| `(4,0,3)` | 拉杆 | 替换此处舱壳，挂在连接器南侧，控制伸缩 |
| `(4,-1,2)` | 船载接收漏斗 | 替换此处滑橇，朝南，从连接器取补给 |
| `(4,-1,3)` | 船载补给箱 | 替换此处滑橇，接收补给 |
| `(7,0,2)` | 岸侧对接连接器 | 朝西，与船侧对齐，中间留两格空气 |
| `(8,0,2)` | 红石块 | 持续为岸侧连接器供电 |
| `(7,-1,2)` | 岸侧漏斗 | 朝东，从上方连接器取货 |
| `(8,-1,2)` | 基地箱子 | 接收卸下的矿物和样本 |
| `(7,1,2)` | 岸侧补给漏斗 | 朝下，将上方物品送入连接器 |
| `(7,2,2)` | 岸侧供给箱 | 放入本次远征所需补给 |

船载部件随船胶合，岸侧设备固定在基地。停采、停机并排干船坞后，给船侧连接器供电，两侧会对齐并锁定，漏斗随后自动卸货。整备时可通过独立离合器停止采掘，改装时保留配平舱顶面的操作空间。

原生连接器需要前方为空气；熔岩会阻止岸侧接口伸出。保持两格伸缩空间畅通，供电拉杆布置在干燥区域。船侧拉杆可在干坞内操作，需要在舱内控制时，可改接 Create 红石链路。

基地箱满时，货物留在货舱、漏斗和连接器缓冲中；腾出空间后继续传输。装卸完成后缩回一侧连接器，确认解锁，再开始出坞灌流和推进。断开期间保留未卸完的货物，重新停靠后可继续。

将本次需要的冷却芯、维修包和弹药放入岸侧供给箱，物品会送入船载补给箱，再在舱内补入调节器和作业设备。两个方向使用独立接收空间，基地卸货箱满时仍可接收补给；任一接收端满载时，对应物资保留在传输链中。

## 近程武装改装

护航配置可将船首右下的采样器 `(3,1,0)` 替换为朝北的压力弩炮，在原发动机位置 `(3,1,1)` 放置沿南北轴的离合器，将发动机后移到 `(3,1,2)`，仍朝北输出。在离合器上方 `(3,2,1)` 放拉杆，打开拉杆即停火，关闭即供能射击。先保持停火，再用弩矢右键补弹。

让探测仪持续供能，依据生物回波轮廓、方向和高度调整船位与炮口。射击产生热量，交战前补足冷却并带上维修包；战后检查外露设备与船壳。兼顾采样时可扩建船首，为采样器和弩炮分别布置工作面、传动和维修通路。
