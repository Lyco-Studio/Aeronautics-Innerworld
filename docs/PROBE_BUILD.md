# 首航探测器搭建指南

这是一台使用 Aeronautics 便携式发动机与 Create 传动件的紧凑型探测器，适合近程采样和熟悉损管。它具有两个独立推进通道、两个配平舱、密闭乘员舱、回声探测仪与采样货舱。

## 船坞与材料

先在地幔顶部岩体中开挖干燥船坞，并建立接驳站补给。准备约一百二十个耐火舱壳、两个观察窗、四个耐压舱门、两个熔岩推进器、两个配平舱，以及各一个舱室调节器、回声探测仪和地幔采样器。另备七台便携式发动机、两个齿轮箱、两个离合器、两个换向齿轮箱、四个拉杆、一个完整照明方块、物理装配器、强力胶和燃煤。

携带冷却芯、维修包与应急封堵板，预留背包和货舱空间。取得安山机壳后，可通过原版配方书查找设备配方。

先在干燥基地内放置并充能重生锚，确认重生点后再出航；预留萤石和备用补给。地幔中使用床会爆炸，床留作主世界或地核营地的重生设施。

## 舱壳与坐标

以船体西北下角为 `(0,0,0)`，X 向东、Y 向上、Z 向南。先搭建宽 5、高 4、长 7 的封闭外壳，即 X=0–4、Y=0–3、Z=0–6；内部 X=1–3、Y=1–2、Z=1–5 保持干燥。

下面的设备替换相应位置的外壳。设备朝向表示其面板或工作面朝向，旋转动力从背面接入。

| 位置 | 放置内容 | 朝向或用途 |
| --- | --- | --- |
| `(1,1,0)`、`(1,2,0)` | 地幔观察窗 | 船首观察 |
| `(2,1,0)` | 舱室调节器 | 面板朝南，通风口朝舱内 |
| `(2,2,0)` | 耐压舱门 | 单格检修口，航行时关闭 |
| `(3,1,0)` | 地幔采样器 | 朝北，船首采样 |
| `(1,0,2)`、`(3,0,2)` | 地幔配平舱 | 朝上，背部轴朝下 |
| `(1,1,6)`、`(3,1,6)` | 熔岩推进器 | 朝南，背部轴朝舱内 |
| `(0,1,2)`、`(0,2,2)` | 耐压舱门 | 同朝向朝西，构成两格高登船口 |
| `(2,3,3)` | 海晶灯或萤石 | 使用完整照明方块，保持舱顶围护 |
| `(0,-1,0)` 至 `(0,-1,6)`、`(4,-1,0)` 至 `(4,-1,6)` | 共十四个耐火舱壳 | 两条同高落地滑橇，与船底胶合 |

在舱内 `(2,1,3)` 放置朝北的回声探测仪。保留登船口到前部乘员位置的通路，查看控制台时站在 `(2,1,2)` 附近。需要更宽敞的维修通道时，可以扩大船体并相应增加配平能力。

两条滑橇与下方传动件的底面齐平，让船体落地时保持水平。改装后继续保持前后均有支撑，并为全部低位部件预留净空。

## 发动机与操控

给七台发动机分别加入煤炭。普通燃煤提供 32 RPM，首次检查不需要增速。

| 发动机位置 | 输出朝向 | 连接设备 |
| --- | --- | --- |
| `(2,1,-1)` | 朝南 | 舱室调节器 |
| `(3,1,1)` | 朝北 | 地幔采样器 |
| `(2,1,4)` | 朝北 | 回声探测仪 |
| `(1,-1,3)`、`(3,-1,3)` | 朝北 | 经齿轮箱向上连接配平舱 |
| `(1,1,3)`、`(3,1,3)` | 朝南 | 左右推进传动通道 |

在 `(1,-1,2)` 与 `(3,-1,2)` 放置齿轮箱，调整到南北与上下均有轴孔，使下方发动机能驱动上面的配平舱。两台配平舱在 32 RPM 时保持深度；总主动配平容量为 256 质量单位。潜行空手右键舱内可触及的配平舱顶面，依次切换转速控制、上浮、下潜，两台应选择相同模式。上浮或下潜模式在普通燃煤转速下即可升降；再次切回转速控制恢复定深。改装和增载后检查是否需要增加配平舱。

左右推进通道沿 Z 轴依次连接：

**发动机 Z=3 → 离合器 Z=4 → 换向齿轮箱 Z=5 → 推进器 Z=6。**

在每个离合器与换向齿轮箱上方放置拉杆。离合器拉杆打开时断开推进，关闭时接通推进；出航前先将两个离合器拉杆打开。左右换向杆统一切换可改变行进方向，单独停止一侧推进器可转弯。

本布局的推进器正转推动船体向南，反转向北；两侧换向杆均打开时朝北部采样口行进。熟悉后可用红石链路将控制移到更方便的位置，或改用无线控制器。需要更快升降时，可在转速控制模式下改装增速与换向传动。

## 装配与首航

1. 在干燥环境中完成围护与传动，关闭全部舱门。调节器与探测仪应已获得动力；用空手查看设备状态，并向调节器补充冷却。
2. 用强力胶连接船体、舱内设备、外置发动机和下方齿轮箱。检查胶合范围，避免连接船坞地面或支架。
3. 在舱顶放置物理装配器，连接到船体并按 Aeronautics 的装配操作组装。打开侧面登船口，进入舱内并关闭。两块登船舱门会联动开关。
4. 完整装配体包括舱顶装配器、下方发动机和船首发动机。为全部轮廓预留空间；本例船坞通道建议至少宽 7、高 8 格，船坞内还需保留改装和装卸空间。
5. 打开船坞与熔岩海之间的机械开口，确认推进器和配平舱浸入熔岩，舱室保持密封。接通两侧推进，低速离坞，尝试停机、转向和倒车。
6. 用探测仪寻找附近矿体，靠近至采样器前方 4 格内。保持船位，采集后空手右键采样器卸货。参照基地距离与方位返航，在干燥船坞开舱并加工矿物、补充燃料和冷却。

配平只能在熔岩中工作，干燥船坞应有平整承托面。以船体全部方块都能进入的净空规划船坞门和航路。出航后先完成近程操控检查，再携带更多货物扩大航程。

## 灌流船坞

侧面开闸后，熔岩会沿坞底流动。为离坞准备单独的顶部灌流口，让落下的熔岩覆盖推进器；灌流与航行空间通过机械闸板控制，生活区和接驳出口保持隔离。

上面的样艇可使用内部 X=-2–6、Y=-1–7、Z=-1–7 的独立坞室，底板位于 Y=-2，顶板位于 Y=8。南侧 Z=8 作为航行闸口；顶板 X=0–4、Z=-1–7 作为灌流口，其上方接熔岩源。灌流覆盖配平舱与推进器，使船体充分浸入熔岩后起浮。为闸板及其运动机构另留空间，用 Create 机械结构控制开合。

1. 关闭航行闸和灌流口，在干坞内完成装配、登船、关舱和冷却补给。
2. 打开航行闸与顶部灌流口，保持舱门关闭。确认推进器报告浸入熔岩，再接通两侧推进，驶离坞室。
3. 返航时保持灌流和航行闸开启。使用两台配平舱的上浮模式，将滑橇升至坞底上方；切回转速控制稳定高度，再低速驶入。确认全部低位设备、船首发动机与尾部都已越过闸板后停机。
4. 关闭航行闸和顶部灌流口，等待流动熔岩消退，确认艇外通道干燥、船体落稳，再开舱。

将熔岩源留在可关闭的灌流口外，坞内采用流动熔岩。两条滑橇承担排干后的落地支撑；整备期间关闭灌流，补充燃煤、冷却和货舱物资。

## 干坞自动卸货

采样货舱可使用普通漏斗接入 Aeronautics 对接连接器。准备两个对接连接器、四个漏斗、一个基地箱子、一个拉杆和岸侧红石电源。向东扩建干坞装卸区，保证岸侧设备、传输通道和操作空间都处于干燥区域。

| 位置 | 装卸设备 | 朝向或用途 |
| --- | --- | --- |
| `(3,0,0)` | 船载漏斗 | 从上方采样器取货，朝东输出 |
| `(4,0,0)`、`(4,0,1)` | 船载漏斗 | 均朝南，将货物送向连接器 |
| `(4,0,2)` | 船侧对接连接器 | 朝东 |
| `(4,-1,2)` | 拉杆 | 替换此处一格滑橇，挂在连接器底部，控制伸缩 |
| `(7,0,2)` | 岸侧对接连接器 | 朝西，与船侧对齐，中间留两格空气 |
| `(8,0,2)` | 红石块 | 持续为岸侧连接器供电 |
| `(7,-1,2)` | 岸侧漏斗 | 朝东，从上方连接器取货 |
| `(8,-1,2)` | 基地箱子 | 接收卸下的矿物和样本 |

船载部件随船胶合，岸侧设备固定在基地。停采、停机并排干船坞后，给船侧连接器供电，两侧会对齐并锁定，漏斗随后自动卸货。采样器后可加离合器，将发动机后移一格，再在离合器上放拉杆，以便在整备时停止采掘。

原生连接器需要前方为空气；熔岩会阻止岸侧接口伸出。保持两格伸缩空间畅通，供电拉杆布置在干燥区域。船侧下方的拉杆可在干坞内操作，需要在舱内控制时，可改接 Create 红石链路。

基地箱满时，货物留在货舱、漏斗和连接器缓冲中；腾出空间后继续传输。装卸完成后缩回一侧连接器，确认解锁，再开始出坞灌流和推进。断开期间保留未卸完的货物，重新停靠后可继续。

## 近程武装改装

护航配置可将船首右下的采样器 `(3,1,0)` 替换为朝北的压力弩炮，在原发动机位置 `(3,1,1)` 放置沿南北轴的离合器，将发动机后移到 `(3,1,2)`，仍朝北输出。在离合器上方 `(3,2,1)` 放拉杆，打开拉杆即停火，关闭即供能射击。先保持停火，再用弩矢右键补弹。

让探测仪持续供能，依据生物回波轮廓、方向和高度调整船位与炮口。射击产生热量，交战前补足冷却并带上维修包；战后检查外露设备与船壳。兼顾采样时可扩建船首，为采样器和弩炮分别布置工作面、传动和维修通路。
