# 三维度生存路线

这条路线从主世界工业准备出发，经地幔基地与熔岩海远征，进入地核迷宫并完成故事。钻机连接三个维度，探测器在地幔组装和运行。

游戏内可用书和铜锭合成远征手册；安装 Patchouli 时，再加一份红石可合成图文任务簿。任务树显示主线、支线与完成状态，阶段奖励按玩家发放一次。

## 主世界工业与钻探

先取得安山机壳、传动部件、红石和铁、铜材料，并提前准备下界砖物品、下界石英及后续加工需要的 Create 部件。首航艇的基础设备使用这些材料，远征收益用于升级。

首台便携式发动机可用手摇曲柄、机械锯和压机制造。铁板交替切割、压制八轮后得到成功总成或失败产物；成功率为 50%，备好重试材料和食物。成功总成再配一张铁板和一座高炉合成发动机。

使用控制器、刀头和 Create 强力胶搭建钻头组件。先检查切削面、储物、动力和操纵器绑定，再开始纵向钻探。主世界默认层界为最低组件方块到达 Y=-58；抵达地幔后钻头暂停，继续下钻进入顶部岩体，再横向开挖基地。

钻机留足燃料。主世界固定动力继续承担接驳通行，船载七台发动机另行备齐。详细刀面、控制与开挖布局见[地幔整备基地开挖指南](DRILL_BUILD.md)。

## 地幔基地与首航

随钻接驳站进入地幔并原生落地后，与主世界站点建立通路。出口前方需要两格干燥净空和稳固地面；通行依赖原钻机继续供能。

先在开挖出的干燥空间布置仓储、工作台、加工设备与重生设施。地幔使用充能重生锚，并储备萤石；床在地幔会爆炸。为生活区和接驳出口保留独立隔断，再施工船坞、出航井及机械闸口。

按[首航探测器搭建指南](PROBE_BUILD.md)逐块建造。样艇有两路推进、两个配平舱、密闭乘员舱、探测仪与采样货舱；七台船载换热发动机分别供能，共用调节器冷却储备。制作本 mod 船体与作业设备需先制成 144 个舱壳，安装完成后余 5 个舱壳、2 个观察窗和 1 个舱门。

加工期间把未完成工件、建艇原料和装配部件分开储存。将七台便携式发动机各用三张铜板和一个储液罐改造成换热发动机，再制作设备并施工。干坞预装冷却、组装和关舱，灌入熔岩后启动机组。完整备料见[远征材料与基地加工](EXPEDITION_SUPPLIES.md)，高位储液和闸控见[机械灌流船坞搭建](DOCK_BUILD.md)。

完成胶合后登艇、关门并操作物理装配器。先检查密封、冷却、双侧推进启停、倒车与配平，再灌流离坞。返航先对齐、低速入坞，关闸排干并确认落稳后开舱。

## 采样、战斗与遗迹

首航用探测仪寻找附近谐振矿。采样口与矿块对齐，保持在四格内并留足整艇净空；用配平舱调整高度，停稳后采集。回基地把粗矿烧成晶体，制作稳定冷却芯，保留返程补给后再扩大航程。

安装压力弩炮时，为炮口、射界、动力和停火控制留出位置；同时保留或安排采样器负责打捞。熔甲掠食者在撞击前有蓄力征兆，交战后检查船壳和外露设备。击败它可获得鳞片，首次防卫任务另奖励四份熟牛肉和经验。船载采样器可以回收熔岩中的掉落物。

收集至少三份鳞片、两张铜板和一块玻璃，制作隔热面罩，另备抗火药水，再安排首次舱外调查。原版抗火抵挡熔岩燃烧，隔热装备延长热暴露时限；干燥廊道和密封舱室用于恢复。

也可对未被激怒的地幔滤食者温和采样，取得粗谐振矿。取样后退开，等待其恢复，再继续作业；留意接近警告。

用探测仪定位观测中继站的底部潜入口，沿台阶游升到干燥廊道，调查补给与档案室。取回合金、工业部件和记录后返回探测器。保留首份合金，可在基地用晶体、鳞片和铁锭重铸补充。

冷却不足会使换热发动机停机，立即向舱室调节器补入冷却芯。低冷却时提前脱离攻击和补给；局部故障或船壳破口时停高负荷作业，封堵、恢复冷却，再在热量降至 70% 或以下时维修。基地保留备用艇、维修包和封堵板，追溯指针可把事故位置载入船载导航。

## 深层升级与地核营地

向深层加工遗址远征前，备好晶体、个人防护、抗火与返程冷却。优先走干燥侧廊，处理守卫并调查档案区；取回耐压矩阵、合金、精密构件和隔离记录。

接续器与测向仪合计需要五份合金、三枚晶体、两个精密构件、一份耐压矩阵和一个指南针。精密构件可从中继站档案或深层遗址取得，也可通过 Create 序列装配制造。取回前厅和档案箱的合金，先预留钻探用量，再分配给装备和补给。

探测器停在地幔。另设固定钻机，将接续器、接驳站与刀面胶合，向下钻至 Y=2 进入地核。继续切削到可落地位置，建立干燥出口和补给连接；外围营地可使用床。

完整备料、长行程接续与九刀面布局见[深层钻探与地核营地](CORE_DRILL.md)。

## 迷宫、守核机与返航

在地核使用测向仪定位迷宫入口，准备剑盾、防具、食物和照明后步行进入。沿通道恢复三处铜制维护节点，再操作核心门前的维护台；未恢复齐全时，维护台会报告缺失节点的位置。

利用前厅、检修间、档案间和高顶汇厅记忆路线。三个节点分别标为 01 回路中继、02 冷却回路、03 隔离维护，拉杆下方的灯反馈状态；节点旁可领取补给和维护记录，检修间可用于整理装备。

持测向仪右键维护台，可检查三个节点的状态与坐标；空手操作才会启动战斗。Boss 条显示暴露和冷却时间，两座冷却阀共用恢复时间；恢复期间拨起的阀会待命，拨回可取消。

守核机用动作、声音与地面预警提示攻击。避开预警区，操作场地冷却阀取得核心暴露窗口，再攻击。后半程注意热区，冷却阀也可清除热区；必要时撤回营地补给。

胜利后取得地核之心，沿原路回到营地，通过钻探站携物返回地幔。实际参与战斗的玩家记录故事通关。基地、航路和遗迹继续保留，可继续探索、加工与改装；通关后潜行操作维护台，消耗四枚晶体可发起复战。
