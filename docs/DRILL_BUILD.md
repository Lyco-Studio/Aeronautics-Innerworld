# 地幔整备基地开挖指南

这套大型钻头从主世界的深部井口出发，在地幔顶部岩体下缘开挖整备间与出航井，再退回井口留下接驳站。开挖区域沿东西方向延伸，宽 11 格、高 11 格；靠近井口的三格用于停放钻头，其后的 21 格可布置首艇整备设施。

刀面尺寸可以按材料和基地规划调整。较小刀面可通过多次平移、分层作业扩建空间；下面给出一套完整刀面的坐标示例。

## 首次试机

正式下井前，可以先在平地搭一台小型水平钻机熟悉操作：

尚无便携式发动机时，先按[手摇加工路线](EXPEDITION_SUPPLIES.md#首航艇备料)压出铁板，经八轮切割与压制制造总成，再与铁板和高炉合成首台发动机。保留钻机所需的铁锭、传动杆与机壳，加工失败的副产物单独存放。

1. 在离地一格的支撑方块顶面，面向南方、潜行放置控制器，使面板朝南、背轴朝北。
2. 在控制器北侧贴轴放置便携式发动机。普通放置会自动对接邻近轴；检查输出轴朝南，再给发动机右键加入煤炭。
3. 在控制器南侧放一个多向掘进刀头，在刀头东侧放箱子，箱内可先存少量物资。刀头前方留出开挖通道。
4. 持强力胶右键刀头选择第一角，再右键箱子确认选区，只胶合这两个方块。选区应避开固定控制器和待开挖的岩石。
5. 空手右键控制器开始，待岩石进入箱子后再次空手右键暂停。停稳后潜行用扳手右键控制器落地，再打开箱子取货。

手持方块可直接贴着控制器放置。调整方向前先暂停；拆装发动机时保持钻头停机。

## 井口与材料

先在主世界建立安全的下井通路与深部作业点。本例将钻头底部放在 Y=-50，固定控制器位于 Y=-49，组件上方需要留出搭建空间。若从更高处开钻，应增加储物容量，沿已开出的井道安排取货，并按每段 128 格的行程上限暂停续行。

准备以下部件：

| 部件 | 数量 |
| --- | ---: |
| 多向掘进刀头 | 143 |
| 木桶 | 4 |
| 钻井接驳站 | 2 |
| 钻探作业控制器 | 1 |
| Create 齿轮箱 | 1 |
| Aeronautics 便携式发动机 | 1 |
| 钻探操纵器 | 1 |
| 煤炭 | 16 |

另备强力胶、扳手、铁镐或更好的镐、食物、照明与基地建设物资。将随行物资放入木桶，预留大部分容量接收开挖产物。需要储存更多物资时可增加木桶，并保证出口和刀面净空。

## 钻头坐标

以组件底部的 `(0,0,0)` 为原点，X 向东、Y 向上、Z 向南。以下位置属于移动组件：

| 位置 | 内容 |
| --- | --- |
| X=0–2、Y=0、Z=-5–5 | 底部刀面，共 33 个刀头 |
| X=2、Y=1–10、Z=-5–5 | 东侧刀面，共 110 个刀头 |
| `(0,1,-3)`、`(1,1,-3)`、`(0,1,-1)`、`(1,1,-1)` | 四个木桶 |
| `(1,1,4)` | 随行接驳站，面板朝西 |

用强力胶分别连接底部刀面和东侧刀面，两者在 X=2、Y=0 的边缘相接。再将每个木桶和随行接驳站与正下方刀头胶合。

完成开挖前保留完整刀面。固定动力设施与主世界接驳站单独布置，胶合范围避开这些设施和井壁。

## 固定动力与主世界接驳站

下面的坐标仍以同一原点表示：

| 位置 | 固定设施 |
| --- | --- |
| `(0,1,0)` | 控制器，面板朝下，背部轴朝上 |
| `(0,2,0)` | 齿轮箱，上下与南北两组面均有轴孔 |
| `(0,2,1)` | 便携式发动机，输出朝北，接入齿轮箱 |
| `(-4,1,0)` | 主世界接驳站，面板朝北 |
| `(-4,0,-1)` | 接驳站出口的稳固地面 |

给发动机加入煤炭。默认普通燃煤提供 32 RPM，经过齿轮箱传给控制器；本布局可使用这一转速直接作业。

进入地幔建设前，再补足固定发动机的燃料，并准备持续补给。接驳站依赖原钻机保持供能，基地建设期间也应维持这条补给通路。

用操纵器右键控制器绑定，再用同一个操纵器接入两座接驳站。主世界站点位于控制器 32 格内，站前应留出两格高的干燥通道。固定控制器和动力留在主世界。

## 纵向抵达与整备间

1. 空手右键控制器，或使用已绑定的操纵器开始向下作业。最低刀头达到 Y=-58 后，组件进入地幔并暂停。
2. 持握操纵器查看高度范围。继续向下开挖，将组件最低高度降至 Y=202，顶部应处于 Y=212，再暂停至整格位置。
3. 记下此时钻头的 X/Z 坐标。潜行使用操纵器选择向东，再开始作业。
4. 向东推进 24 格后暂停。将整备间保留在 Y=202–212，底部仍有天然岩层与熔岩海相隔。

开挖中的木桶会接收岩石与矿物。停机、转向与跨层到达时，都先确认状态已经暂停，再进行下一步操作。

## 出航井与退钻

从上述向东推进 24 格的位置继续：

1. 选择向下，下降 3 格，使最低高度达到 Y=199，然后暂停。
2. 选择向东，再推进 8 格。此时相对最初横向起点共前进 32 格，井底已连接熔岩海。
3. 选择向上，升回最低 Y=202，再暂停。
4. 选择向西，退回最初横向起点。组件离开出航井，给后续船坞和探测器留出通道。
5. 保持暂停，在主世界对原控制器潜行使用扳手，将组件放回地幔世界，等待接驳站连通。

出航井底部为熔岩，先完成地面、围护、照明与机械闸口，再进入井边作业。船坞采用可关闭的顶部灌流口，为船体提供熔岩介质；固定生活区和接驳出口保持干燥。

## 入站与首艇整备

携带镐和建设物资，从主世界接驳站进入。目标站前的底部刀头提供落脚点；向北错开一格，在东侧刀面的 `(2,1,3)` 与 `(2,2,3)` 拆出一格宽、两格高的通道，进入整备间。拆下的刀头可回收复用。

取出木桶里的物资，布置照明、仓储与充能重生锚。先保留原控制器及其动力，维持人员和物资补给。整备间、出航井与固定生活区之间按实际船体轮廓留出净空。

首台探测器及灌流船坞的材料和布局见 [首航探测器搭建指南](PROBE_BUILD.md)。将整套船坞布局转向后布置在整备间内，使航行闸接向出航井；按[机械闸板布局](DOCK_BUILD.md)继续扩建屋顶滑槽、升降行程和固定动力间。高位船坞先用桶或流体设施向顶部储液槽供给熔岩；船坞排干并落稳后再开舱整备。

## 高位船坞与出航井

以首次在 Y=202 开始横向开挖的位置为水平原点，下面的 X/Z 为相对格数，Y 为世界高度。将样艇原点放在 `(16,203,2)`，整套样艇和机械船坞向左转九十度，使搭建图中的南方变为基地东方、东方变为基地北方；航行闸由此朝向出航井。

| 空间 | X 范围 | 世界 Y 范围 | Z 范围 |
| --- | --- | --- | --- |
| 屋顶滑槽、储液区及传动空间 | 11–24 | 210–214 | -8–9 |
| 航行闸及右侧动力间 | 20–24 | 202–217 | -7–3 |
| 井内灌流柱的供液与施工空间 | 25–34 | 210–214 | -3–3 |

按这些位置继续扩建，备好镐、耐久余量和施工台。保持原地板承托，在 X=14 设置固定隔断与两格高舱门，将接驳站和生活区留在西侧干燥区域；船坞与井口位于隔断东侧。

顶部储液区供给受控灌流闸；另外在出航井上方 X=25–33、Y=212、Z=-2–2 保持熔岩供给，形成覆盖样艇上浮路径的井内灌流柱。井内供液与受控船坞分开围护，关闭航行闸后仍能保持生活区和船坞干燥。

供液面上方 Y=213–214 留作放桶和检修净空。井内供液施工时，在 X=25–33、Y=211、Z=-2–2 铺 45 个临时深板岩方块；两侧 Z=-3、3、X=25–34 与远端 X=34、Z=-2–2 共加 25 个 Y=212 的围护方块，其上两格留空，形成可站立的边沿。X=24 的航行闸行程保持通畅。

从两侧逐格放满上方熔岩后，拆除液面下的临时支承，保留源方块与边沿围护，恢复井内净空。受控顶部储槽使用已关闭的闸板承托，两处合计准备 89 桶熔岩，放液后空桶回收复用。详细顺序见[高位储液施工](DOCK_BUILD.md#高位储液施工)。

1. 在干坞内完成建艇、供煤和乘员整备，关舱后打开两闸灌流。
2. 上浮使滑橇离开 Y=201 的承托面，再恢复定深，向东驶入出航井。
3. 全艇越过航行闸后停推，在井内下潜至艇顶低于 Y=200，再进入天然熔岩海。出航前扫描井底与邻近航路，按实际障碍确定开挖和绕行路线。
4. 返航时先在熔岩海中回到井内灌流柱，停推并上浮至滑橇高于 Y=202，再对齐泊位、低速倒车进入干坞。
5. 全艇入坞停稳后关闭两闸，等待流动熔岩退去和船体落稳，再开舱回到固定生活区。

保持固定钻机供能，人员和补给继续通过原接驳连接往返主世界。

已经落地的钻头再次装配时，在地幔另设控制器与动力，使面板贴住组件。先解除接驳站与钻头之间的胶合，保留已连通的站点和出口；补回先前为通行拆下的刀头，再继续扩建基地。
