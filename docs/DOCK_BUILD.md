# 机械灌流船坞搭建

本布局使用 Create 黏性机械活塞、强力胶、离合器与换向齿轮箱控制顶部灌流和航行出口。坐标沿用[首航探测器](PROBE_BUILD.md)：船体西北下角为 `(0,0,0)`，X 向东、Y 向上、Z 向南。整套布局可随基地朝向转向。

先按设备位置扩建屋顶滑槽、升降闸槽和固定动力间。顶部机构延伸至 X=-7–10，航行闸抬起后最高方块位于 Y=14；原先开挖的整备间需要为这些行程继续扩建。生活区、接驳出口与固定操控区保持干燥，使用红石线路或 Create 红石链路连接闸板控制。

左侧固定墙放在 X=-4，为 X=-3–-1 留出施工通道、连续台阶和施工台。铺好船底与地板后，检修沟两端仍需连通侧面通道，使人员可以绕到台阶并继续安装侧壁和舱顶。施工台与船体分别搭建，胶合时避开固定支撑。

## 顶部灌流闸

在 Y=8 用深板岩砖组成一块 X=0–4、Z=-1–7 的完整闸板，并将这 45 个方块胶合。它向东移动五格后停放在 X=5–9，原位置成为进液口。

| 位置 | 内容 |
| --- | --- |
| `(-1,8,-1)` | 黏性机械活塞，面朝东，传动轴朝南北 |
| X=-6–-2、Y=8、Z=-1 | 五根活塞延伸杆，沿东西方向 |
| `(-1,8,-2)` | 换向齿轮箱，南北轴 |
| `(-1,8,-3)` | 离合器，南北轴 |
| `(-1,8,-4)` | 便携式发动机，输出朝南 |
| `(-1,9,-2)`、`(-1,9,-3)` | 分别控制换向齿轮箱和离合器的拉杆 |

滑槽 X=5–9、Y=8、Z=-1–7 保持畅通，其正下方 Y=7 铺固定隔板，使滑槽与坞内隔开。闸板、延伸杆和发动机周围保留固定围护，胶合范围只包含移动闸板。

进液区位于 X=0–4、Y=9、Z=-1–7；`(0,9,-1)` 留作动力间围护。让其余进液区保持熔岩供给，并封住滑槽和传动机构上方的其他进液路径。低于熔岩海的船坞可接入上方熔岩；高位基地使用独立储液槽，通过桶或 Create 流体设施补充。储槽围护应使熔岩经受控闸口进入船坞。

灌流需要覆盖整船至航行出口的范围，使船体、配平舱和推进器充分浸入熔岩。

## 航行升降闸

航行出口位于 Z=8。闸板占 X=-1–5、Y=-1–7，再将顶部 Y=7 的横梁向东延伸到 X=8。

分别胶合整个闸板和顶部横梁：第一组选区为 `(-1,-1,8)` 至 `(5,7,8)`，第二组为 `(-1,7,8)` 至 `(8,7,8)`。两组选区在顶边相接，并避开固定活塞与延伸杆。

| 位置 | 内容 |
| --- | --- |
| `(8,6,8)` | 黏性机械活塞，面朝上，传动轴朝南北 |
| X=8、Y=-1–5、Z=8 | 七根竖直活塞延伸杆 |
| `(8,6,7)` | 换向齿轮箱，南北轴 |
| `(8,6,6)` | 离合器，南北轴 |
| `(8,6,5)` | 便携式发动机，输出朝南 |
| `(7,6,7)`、`(7,6,6)` | 分别贴在换向齿轮箱与离合器西面的拉杆 |

为右侧动力间设置固定围护，传动和开关保持干燥。其顶板覆盖 X=6–9、Y=7、Z=4–7，Z=8 的横梁行程保持畅通。闸板抬高七格后，最低方块位于 Y=6；X=-1–8、Z=8、Y=8–14 的上方闸槽应可通行。

两台固定发动机均需燃煤，动力也可由干燥基地的传动系统接入。为发动机保留补给和检修通道。若在逐块建艇前就启动固定发动机，本示例每台预留十六份煤用于施工等待和闸控；出航前再次核对剩余燃料。也可在施工期间暂不供煤，临近灌流时再启动固定动力。

## 开关与出入坞

本布局中，换向拉杆打开时使活塞伸出，分别打开灌流口与抬升航行闸；关闭时反向收回。离合器拉杆打开时停止传动，关闭时接通。先选方向，再接通离合器，到达行程末端后断开传动。

### 密封舱内无线操控

使用 Create 的无线红石遥控器、转换锁存器和无线红石信号终端，可在关闭舱门后操作两闸。将锁存线路留在干燥生活区，坐标仍沿用本指南的船体坐标：

| 位置 | 内容与设置 |
| --- | --- |
| X=-1、Y=0、Z=-5–-3 | 三格固定支撑平台 |
| `(-1,1,-3)` | 接收终端，朝上，频率为铜锭与时钟 |
| `(-1,1,-4)` | 转换锁存器，输入朝 Z 增大方向，输出朝 Z 减小方向 |
| `(-1,1,-5)` | 发射终端，朝上，频率为铁锭与时钟 |

将顶部换向拉杆 `(-1,9,-2)` 替换为朝上的接收终端；将航行闸换向拉杆 `(7,6,7)` 替换为朝西的接收终端。两者都设置为铁锭与时钟。频率物品顺序需与发射端一致。

在遥控器配置界面为前进键设置铜锭与时钟。两处离合器拉杆保持关闭、接通传动，固定发动机补足煤炭。进入遥控模式后，轻按一次前进键打开两闸，松键后保持开启；再次轻按将两闸关闭。活塞到达五格和七格的完整行程后保持到位，日常开关无需另外操作离合器。

首次使用前确认锁存器输出关闭、两闸均已收回。关闸前先让整船完全进入坞室并停止推进。固定动力间仍保留离合器拉杆，供检修时停机。

### 出入坞顺序

1. 在干坞内完成整备。两侧推进保持断开，乘员登船并关闭全部舱门，补足冷却。
2. 打开航行闸和顶部灌流口，确认两处闸板到位、设备浸入熔岩且舱室密封。
3. 用配平舱上浮，使滑橇离开承托面，再恢复定深并接通两侧推进。低速驶出，确认船首发动机和整船轮廓都已离开闸板行程。
4. 返航前保持两闸开启；用配平对齐泊位，滑橇升过门槛后低速进坞。全艇进入并停机后，再关闭航行闸与灌流口。
5. 等待流动熔岩消退、船体落稳及艇外通道干燥，再开舱、补煤和使用检修沟。

坞内使用流动熔岩，固定熔岩源保留在受控进液口外。闸板行程、升降中的船体和固定动力间应分别留足空间。
