# Aeronautics Innerworld 游戏策划案

## 1. 游戏定位

Aeronautics Innerworld 是面向 Minecraft 1.21.1 / NeoForge 的 Create Aeronautics 附属 mod，围绕地底探险、玩家自建机械载具和失落工业文明展开。

玩家从主世界建立钻探能力，使钻头组件纵向钻入地幔顶部岩体，再横向开挖整备基地。探测器在这座地幔基地内组装，随后驶入熔岩海开展远征。远征获得的矿物、设备和文明线索用于改装探测器、制作个人装备，并解锁通向地核的钻探能力。旅程最终进入以步行为主的地核迷宫，通过角色装备、战斗和机关操作击败最终 Boss，完成故事线。

建造自由、远征准备、途中应变和探索回报构成主要体验。载具的外形、布局、装甲与设备组合由玩家决定，功能需求通过 Create、Aeronautics 和本 mod 的方块与组件实现。

### 设计原则

- 建造服务于探索：钻机、基地和探测器都对应明确的行动能力与生存需求。
- 远征具有取舍：载荷、防护、机动、冷却、探测和火力共同影响可承担的任务。
- 危险可以感知和处理：环境、敌人和设备故障提供预警，玩家能够选择规避、战斗、抢修或返航。
- 成长来自发现与利用：资源和遗迹成果扩展作业方式，并推动地心探索。
- 地幔突出载具与船载设备，地核突出步行迷宫、角色装备和个人战斗。
- 钻机承担三个维度之间的钻探连接；探测器的组装与运行范围均为地幔。
- 单人能够独立完成故事线，多人可以分工协作。

## 2. 核心循环与故事线

远征的基本循环为：

**基地整备 → 扫描目标 → 驾驶出航 → 船载作业与战斗 → 安全区域出舱 → 回收物资 → 返回基地加工、维修和改装。**

远征收益包括取得资源、发现地点、获得线索、回收设备，或建立新的安全据点。玩家依据任务决定装备，采矿、遗迹调查和战斗远征具有不同的装载重点。

### 主线进程

| 阶段 | 玩家行动 | 阶段成果 |
| --- | --- | --- |
| 主世界钻探 | 建立 Create 工业基础，组装钻机，使钻头组件纵向开挖并穿越第一处层界 | 钻头抵达地幔顶部岩体，建立跨层连接 |
| 地幔立足 | 利用钻头横向开挖整备基地，建立补给和返航条件，在基地内组装首台探测器 | 具备熔岩海近程探索能力 |
| 地幔远征 | 扫描、采矿、战斗、进入遗迹和回收工业设备 | 提升载具与个人装备，取得文明线索和深层钻探部件 |
| 深层钻探 | 加工回收材料，升级钻机，使钻头穿越下一处层界 | 建立地核外围营地与补给连接，获得迷宫入口 |
| 地核探索 | 徒步探索迷宫、恢复控制节点、搜集记录并开放核心区域 | 查明地心异常与守核装置的关系 |
| 最终决战 | 使用角色装备、场地机关与战斗技巧击败守核装置 | 失控回路停机，触发故事结局 |

### 故事基础

失落文明曾在地幔与地核之间建立庞大的机械取热设施。地心异常使取热调节系统失控，遗迹中的防卫与维护装置仍在执行旧有指令。玩家从分散的钻探站、加工设施和观测记录中重建事件经过，逐步获得抵达地核的能力。

地核迷宫是取热设施的控制与维护区域。最终 Boss“守核机”为工作名，它持续执行隔离命令，阻止对失控设施的修复。击败守核机后，失控取热回路随之停机，故事线完成。

剧情通过建筑布局、机械状态、可查阅记录和关键发现展开。重要线索可重复读取，主线记录帮助玩家回顾下一步目标。

## 3. 三维度结构

探索范围由原版主世界和两个新增维度组成。

### 3.1 主世界：工业准备与钻探出发地

主世界承担基础采集、Create 工业发展、钻机组装和长期补给。首轮钻探使用主世界材料；首台地幔探测器沿用已建立的 Create 与 Aeronautics 工业体系，并需提前准备耐火结构和探测设备使用的原版下界材料。首航设备不依赖地幔远征材料，后续升级由远征收益推动。

钻机由玩家使用 Create 方块、组件及本 mod 的扩展组件自由搭建。可移动的钻头组件属于 Create 机械结构实体，配合新增方块执行纵向钻探、层界穿越和横向开挖。玩家能够查看钻探方向、动力状态、层界距离和通行条件。

### 3.2 地幔：岩体基地与熔岩海远征

地幔按垂直方向分为三部分：

| 区域 | 地形与环境 | 主要用途 |
| --- | --- | --- |
| 地幔与地壳相接层 | 顶部约 45–60 格厚的深板岩与矿物岩体 | 钻探抵达、开挖基地、基础采矿、建设维修与补给设施 |
| 熔岩海 | 大范围岩浆，分布岩柱、裂隙、矿体、遗迹和危险区 | 探测器航行、船载采掘、战斗、打捞与遗迹调查 |
| 底部层界 | 基岩构成的底部边界，具有可识别的深层钻探目标 | 升级钻机后通向地核 |

顶部岩体具有足够的连续厚度，支持玩家开挖舱室、设备间、仓库、船坞和机械运输空间。钻头穿越层界后抵达这层岩体，玩家利用其横向开挖能力挖出整备基地，再布置设备并组装探测器。初始基地的可用空间来自实际钻探与扩建。

熔岩海通过地形和目标形成可选择的航路。岩柱可遮蔽敌人视线、承载矿体与建筑，裂隙形成狭窄通道，开阔区域适合机动和大型遭遇。不同区域的热环境、敌人分布与资源价值影响远征准备。

完整岩体内部、隔绝熔岩热暴露的基地舱室和遗迹安全空间可供玩家长期活动。向熔岩海敞开的破口与受损防护区域具有明确的高温危险。

### 3.3 地核：外围营地、步行迷宫与最终 Boss

地核包含钻探抵达区、外围补给营地、失落设施迷宫和最终 Boss 场地。钻机建立的连接承担人员与补给往返，外围营地提供仓储、个人整备与返航准备。探测器继续留在地幔承担远征任务。

迷宫路线、机关尺度、资源配置和 Boss 战斗以步行玩家及其角色装备为基准。玩家可使用便携工具和常规搭建策略完成探索。

地幔阶段获得的耐热装备、近身作业工具、战斗装备和便携探测设备在地核中发挥作用，形成从载具远征到个人深入探索的连续成长。

## 4. 跨层钻探与返航

钻机是连接主世界、地幔和地核的唯一跨层机械设施。正在作业且满足条件的钻头组件沿正确方向钻探，达到对应维度配置的层界触发高度后穿越层界。主世界的首次触发高度位于基岩边界上缘可到达的位置，底部基岩仍承担世界边界保护作用。

首次钻入所需的基础层界钻探组件使用主世界可得材料。地幔与地核之间需要由地幔探索取得的材料、工业部件和线索完成钻探升级。

### 纵向钻探与横向开挖

同一套移动钻头组件具备纵向和横向开挖能力。纵向作业用于开辟钻井、接近层界并继续向深层推进；横向作业用于在地幔顶部岩体中扩大工作空间，开挖整备基地、船坞及其通道。

本 mod 的新增方块提供所需的作业控制与方向切换能力，并与 Create 的动力、连接和挖掘组件协作。横向开挖是钻机的实际作业方式，开挖范围与效率取决于玩家搭建的结构、切削面和动力条件。钻头抵达地幔后能够接续横向作业，玩家由此建立首台探测器的组装空间。

### 通行规则

- 跨层移动的机械对象限定为钻机的 Create 钻头组件，其方块组成、附属设备和已有储存内容保持完整。
- 钻机建立的层界连接承担人员与补给往返，连接状态和可用条件应能查看。
- 相邻维度的钻探连接保持水平位置对应，并形成可识别的往返地点。
- 首次钻入地幔时，钻头抵达顶部岩体并保留继续开挖的条件；钻入地核时抵达外围钻探区。
- 通行前明确显示所需空间与受阻原因。抵达区的天然岩体按钻探规则开挖；已有建筑或其他机械结构阻挡时，停止作业并提示。
- 跨层期间暂停钻头推进，抵达后能够恢复控制并继续纵向或横向作业。
- 已打通的层界保留往返条件。返航利用钻机与已建设的通行设施，剧情解锁部件无需在每次往返时重新取得。

首次出发所需的基础动力、维修和返回条件应能在主世界准备。顶部基地建成后可设置正常的补给与重生设施，保障后续远征有恢复地点。

## 5. 地幔基地与远征准备

基地是长期经营的地下工业据点，主要设施包括：

| 设施 | 玩家用途 |
| --- | --- |
| 船坞与停靠区 | 建造、改装、装卸、检查和完整维修探测器 |
| 动力与补给区 | 为载具准备动力所需物资、冷却储备和作业消耗品 |
| 加工区 | 使用 Create 机械处理矿物、制造专用部件与维修材料 |
| 仓储与回收区 | 分拣远征战利品，处理回收设备和残骸 |
| 调查与导航区 | 查阅遗迹记录，整理目标与航路，规划下一次远征 |
| 生活与救援区 | 设置重生、个人补给和备用救援设备 |

玩家先用钻头横向开挖出容纳组装、维修与出入的空间，再在地幔内搭建船坞与探测器。主世界的加工体系通过钻机建立的连接向基地供应材料和部件。

远征出发前，玩家围绕目标检查防护、动力、冷却、工具、弹药、维修材料和货舱余量。近程勘探可由轻型探测器完成，高价值区域需要更充分的防护与回收能力。

新发现的遗迹安全舱室和岩体据点可作为中途补给位置。建立据点的收益是缩短往返距离、增加作业时间和提供事故后的恢复空间。

## 6. 探测器与船载设备

“探测器”指玩家在地幔层内自行搭建并驾驶的探索载具，其组装、航行、维修与改装均在地幔进行；扫描器、采样器等指安装在载具上的具体设备。探测器的活动范围限于地幔，跨层钻探由钻机承担。

探测器沿用 Aeronautics 的装配、驾驶和机械载具玩法，结合本 mod 的耐热防护、熔岩推进、探索作业与战斗组件。玩家可以建造轻型勘探艇、采矿运输艇或重型武装探测器，布局与外形由实际用途决定。

### 设备职责

| 设备类别 | 玩法作用 |
| --- | --- |
| 控制与状态设备 | 驾驶、姿态控制、动力与热状态显示 |
| 耐热结构与装甲 | 构成防护外壳，抵抗环境与局部攻击，保护重要设备和乘员空间 |
| 熔岩推进组件 | 提供熔岩介质中的推进与姿态调整能力 |
| 观察与扫描设备 | 提供近距轮廓、地形回波、目标方位和危险提示 |
| 采掘与采样设备 | 开采熔岩中的矿体，取得样本，执行近距机械作业 |
| 打捞与装卸设备 | 回收遗迹设备、战利品与载具残骸，将其送入货舱 |
| 机械武器与弹药设施 | 进行船载攻击、近距防御和持续作战补给 |
| 换热与冷却设备 | 管理持续受热与作业产生的热负荷，延长有效航程 |
| 损伤监测与维修设备 | 定位故障、准备维修材料并恢复关键设备功能 |
| 货舱 | 储存远征物资、矿物、部件和战利品 |

地幔探测器采用专用熔岩换热发动机：熔岩提供热源，同艇舱室调节器集中储存和补充冷却剂，发动机将热交换转为 Create 旋转动力。机组未组装、离开地幔熔岩或冷却不足时停止输出，补充冷却后自动恢复；停机时仍可手动补入冷却芯。推进、采掘和武器共同影响可用动力，运行机组数量影响冷却消耗。

首航机组可由任意颜色的 Aeronautics 便携式发动机、铜板与储液罐改造，不依赖地幔战利品。在干坞完成装配、关舱和冷却补给后灌入熔岩，确认机组与舱室运行再离坞。燃煤发动机用于主世界工业与干坞调试，基地加工燃料另行准备。

装甲、设备和货物增加负载；机动、防护、航程和作业能力之间形成取舍。核心设备的位置、装甲覆盖和乘员维修通路影响受损后的生存机会。

### 熔岩中的感知

观察设备提供有限距离的局部轮廓与接近提示，帮助玩家避开近处障碍。扫描设备提供更远处的地形、遗迹和大型生物回波；矿体与设备的具体性质通过进一步扫描或采样识别。

玩家能将发现标记为导航目标，并保留返航所需的航路信息。回波需要表达方位、距离与大致类型，让玩家能够据此作出驾驶和探索决策。

## 7. 地幔生态与遗迹

### 7.1 生物与遭遇

熔岩海生物具备适应岩浆的能力，攻击方式围绕船体、设备和航行行为设计。

| 生物角色 | 行为重点 | 玩家应对 |
| --- | --- | --- |
| 领地型中立生物 | 保护巢区或资源点，在受到攻击、碰撞或持续侵扰后反击 | 扫描识别活动范围，绕行或谨慎作业 |
| 熔岩掠食者 | 主动接近和追击目标，攻击外露结构或设备 | 利用预警、地形遮蔽、机动和船载武器应对 |
| 遗迹警戒装置 | 守卫工业设施与关键区域，在入口和内部形成遭遇 | 船载设备处理外部威胁，出舱后使用个人装备与机关作战 |

重要遭遇通过回波变化、环境声、热迹或可见动作提供征兆。中立生物允许玩家通过驾驶和作业方式控制冲突风险；敌对遭遇提供战斗、规避和返航的决策空间。

### 7.2 特殊建筑

| 建筑类型 | 空间特点 | 探索重点 |
| --- | --- | --- |
| 封闭观测站 | 外壳完整，具有入口或停靠空间，内部保留干燥区域 | 出舱调查、环境叙事、基础机械机关与记录回收 |
| 半封闭加工设施 | 外部与部分舱室被熔岩淹没，仍保留独立安全空间 | 船载扫描、清场和打捞，与内部步行探索衔接 |
| 深层钻探遗址 | 位于更危险或更难到达的位置，保留钻探和控制设备 | 获得深层钻探部件与地核线索 |

建筑入口、停靠位置与安全舱室需要可识别。安全性由实际防护和热环境决定，玩家能够观察其状态；损坏外壳或打开暴露通道可能改变可通行范围。

遗迹中的资源分布在船载可作业区域与需要出舱的内部空间。玩家需要选择清场、停靠、保护载具和携带装备的顺序。

## 8. 战斗、损伤与损管

### 8.1 船载战斗

地幔战斗围绕目标识别、距离、姿态、装甲覆盖和武器射界展开。熔岩中可使用专用机械投射武器，近距钻探或防御设备用于处理贴近船体的威胁。

武器消耗弹药、动力或对应作业储备。玩家可通过 Create 工业体系准备与补充这些物资。有效攻击鼓励识别敌人的装甲、弱点和攻击征兆。

采矿与打捞过程中，设备展开、货物装载和动力分配影响应对敌人的能力。玩家能够提前准备逃离路线，决定继续作业、清除威胁或放弃部分收益返航。

### 8.2 局部损伤

损伤以受击方块、重要设备和破口状态为核心。攻击位置与防护布局决定实际影响。

| 受损对象 | 后果 | 损管行动 |
| --- | --- | --- |
| 装甲与结构方块 | 防护下降，严重时方块破坏、重要区域暴露 | 修补外壳、补装防护，调整朝向保护受损侧 |
| 推进、动力或传动设备 | 推力或可用动力下降，姿态与机动受限 | 抢修设备、切换可用动力、降低非必要负载 |
| 观察、扫描、采掘或武器设备 | 相应能力减弱或失效 | 调整任务、保护剩余设备、修复或替换损坏组件 |
| 乘员空间的防护破口 | 内部热暴露上升，威胁乘员与设备 | 定位破口、关闭出入口、应急封堵并降低热负荷 |

设备通过清晰的运行、受损和失效状态反馈问题。监测界面能够指出故障位置、受影响功能及热危险，乘员也能从声响、火花和设备动作变化辨认异常。

### 8.3 抢修与完整维修

事故处理形成以下操作顺序：识别损伤、脱离直接攻击、保护关键设备、封堵危险开口、恢复最低机动能力，再决定继续远征或返航。

现场维修消耗随船携带的材料和备件，重点恢复关键能力。已经完全损毁的设备需要替换；基地船坞提供完整维修、装甲补充和重新装配。

合理布局能够改善损管效率：重要设备有防护，乘员具有可用维修通路，备用动力和备件能够在主设备受损后发挥作用。

### 8.4 热环境与舱外活动

地幔的主要环境威胁为持续高温。耐热围护和冷却设备保护载具及乘员，设备运行、环境暴露和防护破损共同影响热负荷。

抗火效果继续处理燃烧与相应火焰伤害，地幔热暴露另有清晰的预警与防护需求。角色装备可延长短时舱外维修、救援和穿越暴露空间的机会；长期活动依靠探测器、基地或遗迹中的安全空间。

熔岩海中的航行、采掘和战斗以探测器及船载设备为常规手段，个人防护为应急活动提供短时窗口。出舱探索主要在隔绝熔岩的干燥区域进行。

热危险在造成严重后果前提供可辨认的提示和应对时间。封堵破口、恢复冷却、减少高负荷作业和驶入安全区域均可改善状况。

## 10. 地核迷宫与最终 Boss

### 10.1 外围营地与步行路线

外围营地依托钻探连接提供物资接收、仓储、个人补给、重生与返航准备。玩家依据已知危险选择个人装备与消耗品，然后进入迷宫。

迷宫围绕控制与维护设施展开，包含清晰入口、主线通路、调查支线、回环、控制节点、返回营地的捷径和核心场地。支线提供物资、叙事与路线信息，关键节点逐步开放通向核心的路径。

入口前厅、检修间、档案间与高顶汇厅穿插在维护通道之间，形成便于记忆的地标。通道以护墙、横梁、管线和局部灯具表达工业设施的用途；磨损集中在石材与接缝，保留暗处的探索空间。检修间的工作台可用于个人整备。

三处维护节点分别对应回路中继、冷却回路和隔离维护，以编号牌示、设备布置和局部地面标记区分。拉杆下方的指示灯反馈回路状态。核心大厅通过支柱、悬吊灯具、地面环线、侧墙管线和封闭取热装置形成整体空间，冷却阀与检修出口保持可辨认的操作位置。

普通结构允许玩家采掘、搭建和使用机械工具改造路线。关键封锁与核心装置具有可理解的开启条件，机关状态、指示和遗迹记录帮助玩家判断目标。主线在任何正常生成的迷宫中都具有可完成的路线。

### 10.2 最终 Boss：守核机

守核机是失落工业文明的核心维护与防卫装置，受到异常和旧指令影响，持续封锁修复通路。其外观以重型机械、齿轮、管路、护甲与高温核心构成。

Boss 战以角色移动、个人装备、弱点攻击和场地操作为主要手段。完成战斗所需能力由步行装备和场地设施提供，远征准备与战后恢复依托外围营地和钻探补给连接。

| 战斗阶段 | 主要威胁 | 玩家目标 |
| --- | --- | --- |
| 外层防卫 | 有明显征兆的机械打击、护甲保护与场地阻挡 | 熟悉攻击节奏，攻击暴露部位，处理场地控制点 |
| 回路失控 | 热区变化、设施故障与更紧密的攻击组合 | 利用掩体与安全窗口，操作调节设施，维持个人防护 |
| 核心暴露 | 核心弱点开放，守核机进行最后的高强度防卫 | 把握攻击机会，结合装备与场地完成决战 |

各阶段通过动作、机械声、场地变化和状态提示表达转换。装备准备影响容错和行动选择，辨认征兆与正确操作决定战斗推进。

首次击败守核机即完成故事线并触发设施停机与异常稳定的结局。奖励包括纪念物、工业主题收藏和后续改装资源。

## 11. 失败恢复、联机与通关后

### 失败与恢复

- 角色死亡遵循原版死亡及物品保留规则，尊重世界已有设置。
- 玩家可在安全基地和地核外围营地建立补给与重生条件，重生设施失效时遵循原版回退规则。
- 探测器损毁后留下与实际损伤相符的残骸和可回收物资；已发现的事故位置可用于组织救援与打捞。
- 基地和已建设的钻探通道继续承担恢复作用，备用载具与维修储备能够降低事故后的重建成本。
- 关键线索和必要材料保有后续获取途径，单次失败不会永久关闭主线。

### 单人与多人

全部主线以单人可完成为基础。多人可以分工驾驶、操炮、扫描、作业和损管，提高协作效率；角色可以兼任，紧急操作具有清晰优先级。

基地、载具、钻探通道和世界设施由世界中的玩家共同使用。重要记录可重复查阅，通关记录归实际参与的玩家；后来者能够补齐探索与 Boss 战斗。

### 通关后

玩家可继续扩建基地、改装探测器、探索遗迹、采矿、打捞和挑战更高风险的远征目标。地幔仍保有熔岩海、危险与资源，已建设的设施继续发挥作用。

Boss 可通过核心设施再次激活进行复战，首次胜利承担故事结局，复战提供战斗与收藏目标。

## 12. 美术、声音与信息表达

整体风格结合 Create 的机械工业语言、深板岩地层、耐热金属结构和失落文明设施。铜、黄铜、铁、深色岩体与受热发光部件形成统一材质关系。

主世界的钻探设备体现实用工业风；地幔以熔岩明暗、巨大岩柱、局部照明和远处回波营造空间感；地核通过重复机械符号、设施环路和核心装置延续文明线索。

声音承担行动信息：推进与传动声反映载具状态，扫描回波表达目标，异常摩擦、破损和过热警报提示故障，敌人的活动与攻击具有可识别征兆。

驾驶信息优先呈现方向、目标、动力、热状态、关键故障与货舱余量。重要危险同时提供图形、文字或声音反馈，避免仅依赖颜色判断。进入遗迹或地核后，个人装备状态、环境危险、已发现线索与下一处主线目标保持可查阅。
