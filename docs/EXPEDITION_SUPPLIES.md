# 远征材料与基地加工

先在主世界准备 Create 工业设备、下界材料与基础补给，再沿钻井接驳运入地幔。首航艇可以在取得第一份地幔战利品前建成；谐振晶体、熔甲鳞片与遗迹合金用于后续整备和深层升级。

## 首航艇备料

[首航探测器搭建指南](PROBE_BUILD.md)中的标准艇共安装 143 个方块，含两条滑橇与舱内物理装配器。按下表准备成品，另带强力胶、扳手、煤炭及远征补给。

| 成品 | 实际安装数 | 制作时的取整 |
| --- | ---: | --- |
| 耐火舱壳 | 112 | 另有 27 个用于制造下列舱门、窗与设备 |
| 地幔观察窗 | 2 | 制作一次得到 4 个，余 2 个 |
| 耐压舱门 | 3 | 制作两次得到 4 个，余 1 个 |
| 舱室调节器、回声探测仪、地幔采样器 | 各 1 | 各制作一次 |
| 熔岩推进器、地幔配平舱 | 各 2 | 各制作两次 |
| 便携式发动机 | 7 | 颜色不限 |
| 齿轮箱、离合器、换向齿轮箱 | 各 2 | 按配方书准备 |
| 拉杆 | 4 | 两路推进启停与换向 |
| 完整照明方块、物理装配器 | 各 1 | 照明选海晶灯或萤石 |

总共需要制造 139 个耐火舱壳：直接安装 112 个，制作两批舱门消耗 12 个，一批观察窗消耗 1 个，调节器、探测仪和采样器合计消耗 6 个，两台推进器消耗 4 个，两台配平舱消耗 4 个。按每批 8 个制作 18 批，得到 144 个，最终余 5 个。

仅这 18 批舱壳就需要 **72 个铁锭、72 个下界砖物品和 18 张铜板**；舱门、设备与上游机械还需另备材料。下界砖物品由下界岩烧成，配方使用单个下界砖，采购时不要换算成同数量的下界砖块。观察窗、设备、冷却芯与个人防护还会消耗更多铜板和玻璃。

两支电子管分别用于调节器和探测仪，探测仪另需一份下界石英。电子管需要先将下界石英与红石制成玫瑰石英，再用砂纸打磨并配铁板合成。采样器需多向掘进刀头，推进器需螺旋桨，配平舱需储液罐；取得安山机壳后可通过原版配方书查看本 mod 的设备配方。

七台便携式发动机各需一份发动机总成、一张铁板和一座高炉。总成由铁板开始，切割、压制交替进行八轮；每次完成后的成功率为 50%，失败时得到其他铁制品。持续加工直到备齐七份总成，为重试准备铁板和动力。

以上数量对应基础采样艇。固定船坞、钻机、无线闸控、对接装卸、武器改装、备用艇、燃料与冷却储备分别备料；增加船体尺寸时重新计算围护和配平容量。

## 基地加工站

在干燥区域布置工作台、熔炉或高炉、机械压机与置物台。铜锭经压机加工成铜板，用于舱壳、冷却芯和隔热面罩；粗谐振矿在熔炉或高炉中烧成谐振晶体。

为后续合金重铸准备机械搅拌器、工作盆和捕获烈焰人的烈焰燃烧室。搅拌器放在盆上方，中间留一格，燃烧室位于盆下方。搅拌器需要至少 32 RPM；可用大、小齿轮增速，并为烈焰燃烧室投煤保持加热。空手点击盆顶取回加工成品，侧面的配方过滤器用于限制加工目标。

将水桶和普通冷却芯从主世界补给进基地；地幔无法正常放置水源。制作冷却芯后，空桶会返还，可带回主世界重新装水。

## 远征回报与加工

| 材料 | 获取方式 | 主要用途 |
| --- | --- | --- |
| 粗谐振矿 | 采样器开采矿体；对未被激怒的地幔滤食者温和采样 | 烧成谐振晶体 |
| 谐振晶体 | 每份粗谐振矿烧成一枚 | 冷却与维修补给、合金重铸、深层部件及地核复战 |
| 熔甲鳞片 | 击败熔甲掠食者或地幔滤食者 | 隔热装备及维修、合金重铸 |
| 遗迹合金 | 观测中继站和深层加工遗址；取得首份后在基地重铸 | 稳定补给、隔热护衣、深层接续器 |
| 耐压矩阵 | 深层加工遗址档案区，每处两份 | 深层接续器 |
| 精密构件 | Create 序列装配，或探索遗迹取得 | 深层接续器 |

地幔滤食者每次温和采样提供一份粗谐振矿，随后需要一分钟恢复；用供能的采样器接近，保持采样口前方通畅。温和采样不提供鳞片。掠食者掉落 2–4 份鳞片，滤食者掉落 1–2 份；攻击滤食者会使它反击。

观测中继站补给箱提供 3–6 份合金；深层加工遗址提供 4–8 份合金、1–2 个精密构件及两份耐压矩阵。领取后继续探索新海域补充，首份合金保留一份用于重铸。

## 深层升级准备

首次调查前，用三份鳞片、两张铜板和一块玻璃制作隔热面罩，另备抗火药水。取得合金后，可用七份鳞片和一份合金制作隔热护衣。抗火药水负责熔岩燃烧防护，隔热装备延长地幔热暴露时限，转移后及时回到干燥空间冷却。

每个深层钻探接续器需要一份耐压矩阵、四份遗迹合金、两枚谐振晶体和两个精密构件。将接续器与接驳站加入钻头组件，再准备地核营地的照明、床、食物、防具与个人武器。普通冷却芯及维修补给留足地幔返航用量，探测器停放在地幔基地。

例如保留三份合金，再用另一份合金与两枚晶体、两份鳞片和两个铁锭重铸，合计得到五份合金。其中一份可配普通冷却芯制作两枚稳定冷却芯，余下四份用于接续器；还需另备两枚晶体、两个精密构件和一份矩阵。将远征收益分配给补给、个人防护与钻探升级，避免一次用尽返航储备。
