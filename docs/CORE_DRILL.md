# 深层钻探与地核营地

先从地幔远征取得材料并合成深层钻探接续器，再在地幔的干燥作业点搭建钻机。探测器停在地幔，人员和补给通过钻头落地后建立的接驳连接往返。保留已有的主世界—地幔连接，为地幔—地核另建一对接驳站。

## 材料与作业点

准备九个多向掘进刀头、一个深层钻探接续器、一个箱子、两座钻井接驳站、一台作业控制器、一个齿轮箱、一台便携式发动机，以及操纵器、扳手、强力胶和燃煤。接续器使用一份耐压矩阵、四份遗迹合金、两枚谐振晶体与两个精密构件；备料和取得矩阵的路线见[远征材料与基地加工](EXPEDITION_SUPPLIES.md)。

钻井和人员站位分开。为三格宽的移动组件保留竖直通道，固定站点的出口安排在钻井边缘之外，并保留两格干燥净空和稳固地面。普通岩体由刀面切削，箱子接收掉落；不要把控制台、仓储或其他需要保留的设施放在刀面下方。

## 紧凑钻头布局

以底部刀面中心为 `(0,0,0)`，X 向东、Z 向南，以下部件随钻头移动：

| 位置 | 部件 |
| --- | --- |
| X=-1–1、Y=0、Z=-1–1 | 九个多向掘进刀头 |
| `(1,1,1)` | 深层钻探接续器 |
| `(-1,1,1)` | 箱子 |
| `(-1,1,-1)` | 随行接驳站，面板朝东 |

只胶合底部九个刀头，再分别将接续器、箱子和随行站点与其正下方刀头胶合。中央刀头上方留给固定控制器，胶合范围避开控制器及其传动。

在箱子里放入营地补给，预留空间接收开挖产物。随行站点的东侧 `(0,1,-1)` 保持空置；下方刀头会在落地后提供站点出口的落脚面，其上方再留一格净空。

## 固定设施与绑定

| 位置 | 固定设施 |
| --- | --- |
| `(0,1,0)` | 作业控制器，面板朝下，背轴朝上 |
| `(0,2,0)` | 齿轮箱，轴向设为 X |
| `(0,2,1)` | 便携式发动机，输出朝北 |
| `(3,0,0)` | 地幔接驳站，面板朝南 |
| `(3,-1,1)` | 接驳出口的稳固地面 |

站点南侧 `(3,0,1)` 和其上方保持干燥、畅通。固定设施不参与胶合，操作人员也应在移动刀面之外。

1. 给便携式发动机加入煤炭，确认控制器得到旋转动力；普通燃煤的 32 RPM 可直接使用。
2. 用操纵器右键地幔控制器，绑定这台深层钻机。
3. 持同一操纵器，先右键固定的地幔接驳站，再右键随行站点。
4. 站在固定平台上，使用操纵器开始作业。钻头不带乘员跨层。

控制器和发动机始终留在地幔，整备与通行期间持续供煤。原主世界钻机的操纵器与站点另行保留，避免混淆两条连接。

## 钻入地核与落地

向下作业的最低刀头达到地幔 Y=2 后，装有接续器的组件进入地核并暂停。通过操纵器查看层位和最低高度，再次开始向下推进。

每段最多推进 128 格。从地幔顶部开钻时可能需要续行：在行程终点保持暂停，用操纵器潜行右键循环六个方向，回到向下，再开始下一段。转向期间组件保持原位。

地核普通地面在 Y=31。将最低刀头降至约 Y=32，提前暂停并等待整格停稳；遇到维护区屋顶时，刀面可继续切削普通墙体。停机后，在地幔对固定控制器潜行使用扳手，将组件放回地核世界。落地位置受阻时先调整钻头位置，不拆除仍需保留的设施。

随行站点落地后，两座站点会建立往返连接。确认出口有稳固地面、两格干燥净空且无人占用，再空手右键地幔站点前往地核。抵达后先从随行箱子取出照明、床、食物和工具，沿钻井边缘搭出通往地面的安全台阶。

## 营地与迷宫

在地核使用床设置重生点，并保持返程站点与发动机燃料供应。用指南针、一枚谐振晶体和一份遗迹合金合成地核测向仪，寻找实际迷宫入口；在地幔出发前另备这一枚晶体和一份合金，避免将材料全部用于接续器。

先完成补给往返，再携带个人装备进入迷宫。角色步行恢复三处维护节点，操作维护台和冷却阀挑战守核机；探测器继续留在地幔承担远征和资源补给。
