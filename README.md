# Aeronautics Innerworld

面向 Minecraft 1.21.1 / NeoForge、专注于地底探险的 Create Aeronautics 附属 mod。玩家利用钻机连接主世界、地幔和地核，在地幔顶部开挖基地并组装探测器，驾驶探测器探索熔岩海，最终徒步深入地核遗迹。

玩法设计见 [游戏策划案](docs/DESIGN.md)。

## 多向掘进刀头

使用四个铁锭围绕一个安山机壳合成，也可在创造模式的工具与实用物品分类中取得。将刀头装在 Create 移动结构的开挖面，由动力活塞或其他移动机构推进，即可沿行进方向开挖；改变行进方向可用于纵向或横向作业。需要连接多个刀头或其他组件时使用强力胶固定。

刀头保留无法破坏的方块与轨道，遇到这些障碍时需调整作业路线。

## 钻探作业控制器

使用一个安山机壳、两个传动杆、一个红石粉和一个铁锭合成，也可从创造模式的工具与实用物品分类中取得。

将钻头组件贴着控制器的面板一侧搭建，从相反一侧输入旋转动力。组件中至少需要一个机械钻头或多向掘进刀头；使用强力胶连接刀头、机架和箱子，在需要开挖的方向布置切削面。

- 空手右键：首次装配并开始作业，再次点击暂停；暂停后点击继续。暂停会在下一整格位置完成。
- 扳手右键：暂停后选择推进方向，依次为向下、北、东、南、西、向上。转向保留原钻头组件及箱内物品，组件本身不旋转。
- 潜行并用扳手右键：将已暂停的钻头放回世界。落地范围必须可放置，受阻时保留移动组件。

断电会停止推进和设备作业，恢复动力后继续。每段最多推进 128 格；行程结束后重新选向即可开始下一段。

控制器被拆除时，钻头会停放并保留结构及库存。在原位置重建控制器后，用扳手右键钻头重新接入；需要将钻头放回世界时，再对控制器使用潜行扳手操作。

## 地幔钻探

主世界中，向下作业的钻头最低方块到达 Y=-58 时进入地幔。控制器与动力设施留在主世界，钻头抵达后暂停；继续向下开挖，使组件进入岩体范围，再转为横向作业开挖基地。向上钻出地幔天花板可返回主世界，往返保持当前水平坐标。目的地受阻时暂停，清理障碍后可重试。

地幔原型包含 Y=200–255 的 56 格岩体、Y=1–199 的熔岩层和 Y=0 的基岩。原型尚未加入人员通行设施、遗迹、生物或地核。

使用红石粉、两个铜锭、电子管和铁锭合成钻探操纵器，右键控制器绑定。操纵器右键启停、潜行右键循环选向，可在地幔中控制原钻头。作业需持续供能；操纵器操作及钻头附近的玩家会维持所需区块活动。

当前跨层不携带乘员，组件高度最多 64 格，默认最多占用九个目的地区块。主世界触发高度和区块上限可在 `aeronautics_innerworld-server.toml` 中调整。

## 开发

需要 JDK 21，并将 `JAVA_HOME` 指向该 JDK。使用仓库内的 Gradle Wrapper，无需另行安装 Gradle。

```sh
./gradlew build
./gradlew runClient
./gradlew runServer
```

构建产物位于 `build/libs/`。首次运行需要联网下载 Minecraft 和开发依赖。启动专用服务器前，应阅读 Minecraft EULA，并按服务器提示完成配置。

在 IntelliJ IDEA 中以 Gradle 项目打开根目录，将 Gradle JVM 设置为 JDK 21，完成同步后使用生成的客户端或服务器运行配置。
