# Aeronautics Innerworld

面向 Minecraft 1.21.1 / NeoForge、专注于地底探险的 Create Aeronautics 附属 mod。玩家利用钻机连接主世界、地幔和地核，在地幔顶部开挖基地并组装探测器，驾驶探测器探索熔岩海，最终徒步深入地核遗迹。

玩法设计见 [游戏策划案](docs/DESIGN.md)。

用一本书和一个铜锭合成地幔远征手册，可在游戏内查阅钻探、接驳、船体建造、驾驶、采样与损管流程。取得安山机壳后，现有设备与补给配方会加入原版配方书；取得书时会解锁手册配方。进度界面提供从钻探准备到样本加工的探索路线。

## 多向掘进刀头

使用四个铁锭围绕一个安山机壳合成，也可在创造模式的工具与实用物品分类中取得。将刀头装在 Create 移动结构的开挖面，由动力活塞或其他移动机构推进，即可沿行进方向开挖；改变行进方向可用于纵向或横向作业。需要连接多个刀头或其他组件时使用强力胶固定。

刀头保留无法破坏的方块与轨道，遇到这些障碍时需调整作业路线。

## 钻探作业控制器

使用一个安山机壳、两个传动杆、一个红石粉和一个铁锭合成，也可从创造模式的工具与实用物品分类中取得。

将钻头组件贴着控制器的面板一侧搭建，从相反一侧输入旋转动力。组件中至少需要一个机械钻头或多向掘进刀头；使用强力胶连接刀头、机架和箱子，在需要开挖的方向布置切削面。

- 空手右键：首次装配并开始作业，再次点击暂停；暂停后点击继续。暂停会在下一整格位置完成。
- 扳手右键：暂停后选择推进方向，依次为向下、北、东、南、西、向上。转向保留原钻头组件及箱内物品，组件本身不旋转。
- 潜行并用扳手右键：将已暂停的钻头放回世界。落地范围必须可放置，受阻时保留移动组件。

断电会停止推进和设备作业，恢复动力后继续。每段最多推进 128 格；行程结束后重新选向即可开始下一段。

控制器被拆除时，钻头会停放并保留结构及库存。在原位置重建控制器后，用扳手右键钻头重新接入；需要将钻头放回世界时，再对控制器使用潜行扳手操作。

## 地幔钻探

主世界中，向下作业的钻头最低方块到达 Y=-58 时进入地幔。控制器与动力设施留在主世界，钻头抵达后暂停；继续向下开挖，使组件进入岩体范围，再转为横向作业开挖基地。向上钻出地幔天花板可返回主世界，往返保持当前水平坐标。目的地受阻时暂停，清理障碍后可重试。

地幔原型包含 Y=200–255 的 56 格岩体、Y=1–199 的熔岩层和 Y=0 的基岩。熔岩海中有高低不一的玄武岩柱，部分连接顶部岩体；可绕行、从柱顶越过或用船载采样器开路，柱内也埋有少量谐振矿。上部熔岩中分布谐振矿和观测中继站，下部有深层加工遗址，可驾驶探测器勘探、采集和调查；熔甲掠食者会威胁航行中的探测器。升级钻头可进入地核建立营地，随后徒步调查维护迷宫并挑战守核机。

使用红石粉、两个铜锭、电子管和铁锭合成钻探操纵器，右键控制器绑定。操纵器右键启停、潜行右键循环选向，可在地幔中控制原钻头。作业需持续供能；操纵器操作及钻头附近的玩家会维持所需区块活动。

当前跨层不携带乘员，组件高度最多 64 格，默认最多占用九个目的地区块。主世界触发高度和区块上限可在 `aeronautics_innerworld-server.toml` 中调整。

## 钻井接驳站

使用两个铁锭、一个铜锭、两个传动杆、一个安山机壳、两个红石粉和一个电子管合成。接驳站承担玩家与背包物资的往返，需要原钻机持续供能。

1. 在主世界控制器 32 格以内放置第一座接驳站，用已绑定该控制器的操纵器右键接入。
2. 将第二座接驳站装入钻头组件，同样用操纵器接入，并使用强力胶固定。
3. 钻入地幔，继续纵向和横向开挖。目的站正前方需要两格干燥净空及稳固地面，切削面应覆盖出口头顶的空间。
4. 暂停后，在主世界对控制器潜行使用扳手，将组件放回地幔世界。接驳站随之连通。
5. 空手右键站点通行，潜行空手右键查看目的地。携带的物品随玩家保留，连续通行之间需稍作等待。

已连通的接驳站作为固定设施保留。复用钻头时先解除它与站点之间的强力胶连接，保留站点和出口。站点损毁后，可在原层放置替代站并用操纵器重新绑定；移动站点前先拆除旧站，再绑定新站。

## 地幔探测器设备

耐火舱壳、地幔观察窗和耐压舱门用于搭建封闭舱体；熔岩推进器、地幔配平舱和舱室调节器均从背面接入 Create 旋转动力。全部设备具有生存合成配方。

- 在干燥的整备空间建造并用强力胶连接结构，使用 Aeronautics 的物理装配器组装。出航前排空舱内积液，关闭舱门。
- 将舱室调节器的通风面朝向舱内，提供至少 16 RPM。每个舱室需要完整围护；关闭的耐压舱门能够密封，空手右键可开关。单个调节器支持最多 4096 格舱内空间，舱室各方向距离通风口不超过 16 格。
- 熔岩推进器的格栅面标示正向推力。反转动力可倒车；两侧推进器采用不同转向或转速可以转弯。设备浸入地幔熔岩后工作。
- 地幔配平舱在 32 RPM 时稳定深度；高于 32 RPM 的正转控制上浮，高于 32 RPM 的反转控制下潜，96 RPM 对应约每秒一格的目标升降速度。每台最多为 128 质量单位提供主动配平，大型结构需要增加配平舱。
- 空手右键设备查看当前状态。配平舱和推进器需要安装在能够浸入熔岩的位置；舱内可布置照明、动力、储物和驾驶设施。

舱门开启、舱壳出现破口或调节器失去动力时，舱内保护会失效。进入干燥船坞后再开舱；探测器在地幔组装和运行。

同朝向的耐压舱门上下叠放，可形成两格高的登船通道；操作其中任意一扇会同时开关相邻舱门。燃煤发动机、离合器与换向操控的搭建示例见 [首航探测器搭建指南](docs/PROBE_BUILD.md)。

## 勘探、采样与返航

首航前安装回声探测仪和地幔采样器，两者均从背面接入旋转动力。将探测仪布置在舱内便于查看的位置，面板朝向需要观察的方向；采样器的采掘面朝向船外。

- 回声探测仪需要至少 16 RPM，探测周围 16 格内最近的谐振矿，并测量面板前方最多 16 格的地形净空。空手右键查看矿物类型、坐标、距离、基地泊位和故障位置。
- 工作中的探测仪会标记 32 格内熔岩生物的轮廓，帮助在熔岩中辨认目标。接近生物时，状态栏优先显示敌对目标的类型、距离、方位和高度；空手右键可取得具体坐标及滤食者的采样恢复时间。
- 探测仪放置时记录初始泊位；在干燥船坞内潜行空手右键可重新记录。靠近工作中的探测仪时，状态栏显示高度、前方净空、速度、基地距离及方位、热量、冷却余量和故障数量。
- 地幔采样器在装配后的探测器上工作，采掘正前方 4 格内的谐振矿与可采岩体。采掘面与目标之间不能有其他实体方块遮挡；靠近目标后保持位置并提供旋转动力。
- 采样器自带九格货舱，满载时暂停开挖。空手右键将第一组货物转入背包，潜行空手右键查看状态；也可通过物品搬运设备装卸。

谐振矿主要分布在新生成地幔区块的 Y=164–196 附近，深层岩柱也有少量埋藏。采集得到粗谐振矿，可用熔炉或高炉加工为谐振晶体。一个晶体与两个普通冷却芯可合成两个稳定冷却芯；晶体也能与铁板、红石合成更多维修包。首航所需的普通冷却芯、维修包和封堵板均可用主世界材料制造。

地幔滤食者通常保持中立。将采样口对准 4 格内的平静滤食者，可温和取得一份粗谐振矿；同一生物约一分钟恢复一次，货舱满载时保留采样机会。持续贴近会先触发警告，继续侵扰或攻击会使其反击，采样时应保持距离并及时离开。

## 冷却与损管

出航前携带冷却芯、维修包和应急封堵板。使用铜板、玻璃和水桶合成冷却芯；用冷却芯右键舱室调节器补充储备。普通冷却芯提供 120 秒冷却，稳定冷却芯提供 240 秒，单个调节器最多储备 600 秒。

熔岩环境与动力设备运转会增加热负荷。调节器供能时消耗冷却储备降温，驶入干燥船坞后可自然降温。热量达到 60% 时出现预警；满热持续 10 秒会使运转中的推进或配平设备故障，并损坏局部舱壳，继续过热会击穿裂损部位。

1. 通过探测仪定位故障设备和破损舱壳，降速并补充冷却。
2. 发生破口时用应急封堵板补上缺口。调节器有足够冷却储备时会启动一次应急喷淋，为原舱内乘员提供 5 秒抗火保护。
3. 将热量降至不高于 70%，再用维修包右键故障设备或破损舱壳，恢复动力或完整舱壳。无需维修或温度过高时不会消耗维修包。
4. 重新封闭并供能，确认舱室恢复密封，再返航整备。

抗火药水只能延缓普通熔岩伤害，无法抵消地幔热暴露。暴露约 3 秒会出现警告，5 秒后开始持续受伤；在熔岩海中应保持舱室完整，出舱探索需先抵达干燥空间。

## 船载还击与舱外防护

压力弩炮安装到探测器后，从背面输入至少 16 RPM 即可射击。炮口朝向决定弹道，可用 Create 离合器控制开火；提高转速可提高射速，最高每秒约两发。射击与采样都会增加热量，持续作业时检查冷却储备。

使用压力弩矢右键弩炮补弹，弹仓最多 64 发；空手右键查看状态，潜行空手右键卸弹。弩矢可用两个铁锭和一根线合成 16 发，物品搬运设备也能装卸弹药。

熔甲掠食者适应熔岩，会追击附近乘员，并在蓄力声和身体抖动后撞击船体。撞击可使耐火舱壳裂损、击穿较脆弱的结构，或使外露推进与配平设备故障。利用生物回波调整朝向还击，受损后及时停火、检查破口并抢修。

击败掠食者得到熔甲鳞片，可制作隔热面罩和隔热护衣。单独穿戴面罩将热暴露时限延长到 10 秒，护衣为 15 秒，同时穿戴为 20 秒；成套装备还会提供短时抗火。超过时限仍会受到地幔热伤害，应及时返回干燥空间或密封舱冷却。装备可用熔甲鳞片维修。

## 观测中继站

新生成的地幔区块会出现失落文明的观测中继站。空手右键工作的回声探测仪，可取得附近 128 格内中继站的坐标、距离和大致方位；继续驶入新海域可发现更多站点。

中继站从底部潜入口接近，上方为干燥廊道与档案室。先确认可登上的干燥区域，再短时出舱沿台阶进入；出发前准备冷却与抗火补给，避免长时间暴露。内部同朝向的两扇隔门可以联动开关。

补给箱提供煤炭、冷却芯、维修包、封堵板与遗迹合金；档案室留有观测记录和工业部件。遗迹合金可提高维修包产量，或以较少的普通冷却芯制成稳定冷却芯。每座遗迹的箱内物资领取后保留已取走的状态，后续可探索其他站点补给；观测记录可保留、传阅或按原版书本规则复制。

取得首份遗迹合金后，可在加热搅拌盆中加入一份合金、两份谐振晶体、两份熔甲鳞片和两个铁锭，重铸为两份合金。勘探、温和采样与战斗所得材料可持续用于基地加工。

## 深层钻探与地核营地

深层加工遗址位于熔岩海下部，回声探测仪可报告附近 128 格内的遗迹。底部潜入口连接干燥侧廊；中央加工区保留熔沟，并有岩浆怪侵扰。沿侧廊调查档案区，可取得两份耐压矩阵、遗迹合金、精密构件和深层记录。继续探索新海域可找到更多遗址，补充部件。

用一份耐压矩阵、四份遗迹合金、两份谐振晶体和两个精密构件合成深层钻探接续器。在地幔基地设置钻探控制器，将接续器和接驳站用强力胶固定在钻头上；向下钻至最低方块 Y=2 时进入地核。未安装接续器时钻头会暂停并提示升级。地核通路与主世界通路分别使用所在上层的控制器。

抵达后继续下降，接近地面时暂停并将钻头放回世界。在控制器 32 格内绑定一座地幔接驳站，与随钻头落地的地核站点建立连接。出口需要稳固地面、两格干燥净空；床可在地核使用，适合建立补给、重生和返航营地。探测器留在地幔，地核探索准备以食物、照明和个人装备为主。

钻头向上越过地核上界可返回地幔的原钻探高度；目的地受阻时保持暂停，清障后重试。

## 地核迷宫与守核机

用指南针、谐振晶体和遗迹合金合成地核测向仪，在地核右键取得维护迷宫入口坐标。入口由铜柱标识，内部通道连接三处铜制维护节点、补给记录及核心场地。普通墙体允许开挖，可按自己的方式标记路线或开辟通路。

开启三处节点的拉杆，再空手操作核心门前的维护台。未恢复全部节点时，维护台会报告一处缺失节点的位置；全部恢复后解除隔离并启动守核机。场地侧面保留返程出口，可回到营地整备。

守核机用机械动作、声音和地面预警圈提示攻击。离开预警范围后再还击；操作场地内两座冷却阀，可让核心暴露约八秒，冷却回路约十五秒后恢复。暴露时攻击收益更高，最后阶段核心持续开放。食物、个人武器、防具及营地补给决定可持续作战的能力。

击败守核机后，失控取热回路停机，实际参与且在线的玩家获得故事通关进度，撤回营地的参与者也会计入，并留下停机核心。未能完成时可以返回补给后继续，已建成的航路仍可使用。通关后潜行空手操作维护台，消耗背包内四枚谐振晶体可发起复战。

## 事故恢复

用指南针、两枚谐振晶体和两份遗迹合金合成原版追溯指针。在上次死亡所在维度使用，可定位死亡地点；死亡掉落仍遵循世界规则。

基地应保留备用探测器、冷却芯、维修包和个人防护。撤离时记录事故坐标，乘备用艇接近残骸；先封堵破口、补充冷却，再维修残存设备。完全损毁的方块需重新补装，原有接驳通路继续用于运送人员和重建物资。重要遗迹材料可通过继续探索补充，遗迹合金也可在基地重铸。

## 开发

需要 JDK 21，并将 `JAVA_HOME` 指向该 JDK。使用仓库内的 Gradle Wrapper，无需另行安装 Gradle。

```sh
./gradlew build
./gradlew runClient
./gradlew runServer
```

构建产物位于 `build/libs/`。首次运行需要联网下载 Minecraft 和开发依赖。启动专用服务器前，应阅读 Minecraft EULA，并按服务器提示完成配置。

可运行 `python3 tools/check_resources.py` 检查资源与翻译。仓库的构建工作流使用 JDK 21 完成编译和资源检查；需要游戏世界或图形桌面的运行场景见 [实施目标与验证说明](GOAL.md)。

在 IntelliJ IDEA 中以 Gradle 项目打开根目录，将 Gradle JVM 设置为 JDK 21，完成同步后使用生成的客户端或服务器运行配置。
